ChatGPT에서 마이크를 눌렀는데 말한 내용이 글자로만 입력되고, 기대했던 음성 답변은 나오지 않나요? 이때는 마이크 고장보다 **받아쓰기와 음성대화를 구분하는 것**이 먼저입니다. 받아쓰기는 말을 입력할 글자로 바꾸는 기능이고, 음성대화는 ChatGPT와 말로 주고받는 기능입니다.

음성대화를 시작하려면 ChatGPT에 로그인한 뒤 입력창의 **Voice 버튼**을 선택하고 마이크 사용을 허용하면 됩니다. 대화할 때의 목소리는 ChatGPT 설정의 Voice 항목에서 바꿀 수 있습니다. 내 말을 못 알아듣는 문제는 마이크 쪽을, 답변 소리만 안 들리는 문제는 스피커·이어폰 쪽을 따로 확인하는 편이 빠릅니다.

아래는 **2026년 9월 27일 확인한 공식 안내**를 바탕으로 정리한 사용법입니다. 실제 캡처는 Windows의 Chrome 웹 화면과 공식 도움말이며, 로그인 이후의 음성 송수신과 모바일 조작을 직접 시험한 후기는 아닙니다. 앱 버전과 계정에 따라 버튼 모양이나 메뉴 번역은 다를 수 있어 공식 영문 이름도 함께 적었습니다.

## 받아쓰기와 음성대화의 차이

[OpenAI의 받아쓰기 안내](https://help.openai.com/en/articles/12168547-voice-dictation-faq)에 따르면 마이크 아이콘으로 녹음한 말은 텍스트로 변환됩니다. 변환된 문장을 확인하고 수정한 뒤 메시지로 보내는 방식입니다. **마이크 버튼을 눌렀다는 사실만으로 음성대화가 시작된 것은 아닙니다.**

| 하고 싶은 일 | 선택할 기능 | 시작 뒤 확인할 모습 |
| --- | --- | --- |
| 긴 질문을 키보드 대신 말로 입력 | 받아쓰기, Dictation | 변환된 글을 확인하고 수정한 뒤 전송 |
| 질문과 답을 말로 주고받기 | 음성대화, Voice | 대화 중 마이크 음소거와 종료 제어 사용 |

따라서 말한 내용이 입력창의 글자로 돌아왔다면 받아쓰기가 작동한 것입니다. 음성대화를 원했다면 입력창에서 별도의 Voice 제어를 찾아 시작해야 합니다. 스마트폰 키보드 자체의 마이크도 ChatGPT 음성대화를 여는 버튼과는 다릅니다.

## 시작 화면과 음성대화 진입

처음에는 **iPhone·Android의 ChatGPT 앱 또는 PC의 chatgpt.com**에서 시작하면 됩니다. 이 글은 일반 채팅의 음성대화를 다루며, 데스크톱 앱에서 에이전트에게 작업을 맡기는 Voice in Desktop은 범위에서 제외합니다.

아래는 로그인하지 않은 웹 시작 화면입니다. 입력창 오른쪽에 마이크가 보이지만, 이 화면에서 확인한 버튼의 이름은 ‘받아쓰기 시작’입니다. 같은 모양의 버튼을 보고 음성대화까지 사용할 준비가 됐다고 판단하면 헷갈리기 쉽습니다.

<Image src="/chatgpt-voice-guide/00.png" alt="ChatGPT 로그인 전 웹 시작 화면과 입력창 오른쪽의 받아쓰기 마이크" caption="chatgpt.com 실제 캡처. Windows·Chrome, 2026년 9월 27일. 로그인 후 Voice 화면과는 구분해야 합니다." />

### iPhone·Android 앱

[ChatGPT Voice 공식 안내](https://help.openai.com/en/articles/20001274-chatgpt-voice)의 시작 순서는 다음과 같습니다.

1. ChatGPT 앱에 로그인하고 대화 화면을 엽니다.
2. 메시지 입력줄의 **Voice 아이콘**을 선택합니다. 받아쓰기용 마이크와 구분합니다.
3. 마이크 접근 요청이 나타나면 ChatGPT 앱의 마이크 사용을 허용합니다.
4. 첫 음성대화에서 목소리 선택 화면이 나오면 원하는 목소리를 고릅니다.
5. Voice가 열린 뒤 짧게 말을 걸어봅니다. 대화 중 마이크 제어로 내 목소리를 음소거하거나 다시 켤 수 있고, 종료 제어로 음성대화를 끝낼 수 있습니다.

### PC 웹

1. [chatgpt.com](https://chatgpt.com)에 접속해 로그인합니다.
2. 프롬프트 입력창의 **Voice 아이콘**을 선택합니다.
3. 브라우저가 마이크 접근을 요청하면 현재 ChatGPT 사이트의 사용을 허용합니다. Chrome에서는 ‘이번만 허용’이나 ‘사이트에 있는 동안 허용’ 등의 선택지가 나타날 수 있습니다.
4. Voice가 열리면 말을 시작합니다. 대화를 마칠 때는 종료 제어를 누릅니다.

첫 확인용으로는 ‘한국어로 짧게 인사해 주세요’처럼 개인정보 없는 문장이 적당합니다. **내 질문에 맞는 음성 답변이 들리는지 확인하고, 종료 후 같은 채팅의 기록을 살펴보세요.** 글자 변환만 됐는지, 실제로 소리를 주고받았는지를 구분하는 완료 기준입니다. 다만 음성대화 기록은 발언을 한 글자도 빠짐없이 옮긴 속기록은 아니므로 중요한 내용은 다시 확인해야 합니다.

## 마이크 권한 복구

처음 뜬 권한 창에서 거부했더라도 다시 설정할 수 있습니다. 앱 안의 마이크 음소거, 운영체제의 접근 권한, 웹브라우저의 사이트 권한은 서로 다른 설정입니다. **한 곳만 켰다고 모든 차단이 해제되는 것은 아닙니다.**

### iPhone의 앱 권한

iPhone의 **설정 → 개인정보 보호 및 보안 → 마이크**에서 ChatGPT의 접근을 켭니다. [Apple 안내](https://support.apple.com/ko-kr/guide/iphone/iph168c4bbd5/ios)에 따르면 여기에 표시되는 것은 마이크 접근을 요청한 앱입니다. ChatGPT가 목록에 없다면 앱으로 돌아가 Voice를 시작해 권한 요청이 나타나는지 먼저 확인합니다.

### Android의 앱 권한

Android의 기본 경로는 **설정 → 앱 → ChatGPT → 권한 → 마이크**입니다. 앱을 찾지 못하면 ‘모든 앱 보기’를 먼저 엽니다. [Google 안내](https://support.google.com/android/answer/9431959?hl=ko)에 따라 ‘앱 사용 중에만 허용’ 등 필요한 범위의 권한을 선택합니다.

제조사와 Android 버전에 따라 메뉴 이름은 다를 수 있습니다. 앱 권한이 허용돼 있는데도 안 된다면 기기 전체의 ‘마이크 액세스’가 꺼져 있는지도 확인합니다. 다른 앱의 권한까지 전부 켤 필요는 없습니다.

### Chrome과 Windows의 권한

Chrome에서는 **설정 → 개인 정보 보호 및 보안 → 사이트 설정 → 마이크**를 엽니다. 사용이 차단된 사이트 목록에 `chatgpt.com`이 있다면 해당 사이트의 마이크 권한을 수정합니다. 연결된 마이크가 여러 개라면 같은 마이크 설정에서 사용할 기본 장치도 확인합니다. 자세한 경로는 [Chrome 공식 도움말](https://support.google.com/chrome/answer/2693767?hl=ko)에 나와 있습니다.

<Image src="/chatgpt-voice-guide/01-chrome-permissions.png" alt="Chrome의 chatgpt.com 사이트 설정에서 마이크와 소리 권한을 따로 표시한 화면" caption="Chrome 152의 실제 사이트 권한 화면. 마이크는 요청 상태, 소리는 자동 상태입니다." />

위 화면처럼 **마이크와 소리는 별도 항목**입니다. 마이크의 ‘요청’은 사용할 때 허용 여부를 묻는 상태이지, 그 자체로 오류는 아닙니다. 다른 권한을 한꺼번에 재설정하거나 사이트 데이터를 지우기보다 필요한 항목부터 확인하세요.

Windows 11에서는 브라우저 설정과 별개로 **설정 → 개인 정보 및 보안 → 마이크**를 확인합니다. [Microsoft 안내](https://support.microsoft.com/en-us/windows/privacy/turn-on-app-permissions-for-your-microphone-in-windows)에 따라 마이크 접근과 앱 접근을 확인하고, Chrome 같은 데스크톱 프로그램에는 ‘데스크톱 앱에서 마이크에 액세스하도록 허용’도 켜져 있어야 합니다. 이 항목은 특정 사이트만이 아니라 데스크톱 앱 전반에 영향을 주므로 사이트별 허용은 Chrome에서 따로 관리합니다.

권한을 바꾼 뒤에는 ChatGPT 화면으로 돌아가 새로고침하거나 앱을 다시 열고 Voice를 시작합니다. 회사·학교 관리 기기에서 설정이 잠겨 있다면 정책을 우회하지 말고 관리자에게 확인해야 합니다.

## 목소리와 언어 변경

목소리를 바꾸는 곳은 휴대전화의 Siri나 접근성 음성 설정이 아니라 **ChatGPT 자체 설정**입니다. 현재 공식 경로는 **Settings → Voice → Voice**입니다.

1. ChatGPT의 메뉴에서 **Settings**를 엽니다.
2. **Voice** 항목으로 들어갑니다.
3. 그 안의 **Voice** 선택에서 원하는 목소리를 고릅니다.
4. 대화를 시작해 선택한 목소리로 응답하는지 확인합니다.

공식 도움말에는 Arbor, Breeze, Cove, Ember, Juniper, Maple, Sol, Spruce, Vale이 안내돼 있습니다. OpenAI는 Cove를 차분하고 직접적인 목소리, Spruce를 차분하고 긍정적으로 반응하는 목소리로 설명합니다. 이런 설명을 참고해 후보를 고른 뒤, 평소 사용할 언어로 짧게 대화하며 듣기 편한 쪽을 선택하면 됩니다.

<Image src="/chatgpt-voice-guide/02-voice-options.png" alt="OpenAI 공식 도움말의 Settings Voice 경로와 목소리 선택 목록" caption="OpenAI ChatGPT Voice 도움말의 목소리 변경 부분을 발췌한 실제 캡처. 2026년 9월 27일 확인." />

[공식 안내](https://help.openai.com/en/articles/20001274-chatgpt-voice#change-your-preferred-voice)는 **대화 중 목소리를 바꾸면 같은 채팅 안에서 새 음성 통화가 시작된다**고 설명합니다. 채팅을 새로 만들어야 한다는 뜻은 아니지만, 통화는 전환되므로 긴 설명을 하던 중보다 잠깐 대화를 멈춘 뒤 바꾸는 편이 낫겠습니다.

한국어 인식이 어색하다면 **Settings → Voice → Language**에서 주로 말하는 언어를 선택합니다. 대화 중 ‘한국어로 답해 주세요’, ‘조금 천천히 말해 주세요’라고 요청할 수도 있습니다. 다만 말하는 속도를 요청하는 것과 재생 배속을 정확한 숫자로 고정하는 것은 다릅니다. 현재 공식 안내에서는 정밀한 재생 속도 제어를 제공하지 않는다고 설명합니다.

## 소리가 안 들릴 때의 확인 순서

마이크 권한은 **내 소리를 ChatGPT에 보내는 쪽**입니다. 내 말에 대한 답변은 화면에 나오는데 음성만 안 들린다면, 마이크 권한을 반복해서 바꾸기보다 출력 쪽을 먼저 확인하는 게 좋습니다.

### 답변 음성의 출력 확인

1. **Voice로 시작했는지 확인합니다.** 받아쓰기로 질문을 입력해 일반 텍스트 답변을 받은 것이라면 음성대화로 다시 진입합니다.
2. **답변이 재생되는 동안 볼륨을 올립니다.** 벨소리 음량만 확인하지 말고 현재 재생 중인 오디오 음량을 확인합니다.
3. **소리가 나가는 장치를 확인합니다.** Bluetooth 이어폰이나 다른 스피커로 연결돼 있다면 원하는 출력으로 바꿉니다. 연결을 잠시 끊고 기기 스피커에서 들리는지 비교할 수도 있습니다.
4. **웹에서는 사이트 음소거와 ‘소리’ 권한을 확인합니다.** Chrome 탭의 우클릭 메뉴에 사이트 음소거 해제 항목이 있는지 살펴보고, 앞서 본 `chatgpt.com` 사이트 설정의 ‘소리’가 차단돼 있지 않은지 확인합니다.
5. **Windows에서는 출력 장치와 앱별 볼륨을 확인합니다.** 설정 → 시스템 → 소리에서 실제로 듣고 있는 스피커·이어폰을 고르고, 볼륨 믹서에서 브라우저가 음소거돼 있지 않은지 확인합니다.

Windows의 출력 장치·앱별 음량은 [Microsoft 소리 문제 해결 안내](https://support.microsoft.com/en-us/windows/hardware/audio/fix-sound-or-audio-problems-in-windows)를 참고할 수 있습니다. Android에서는 [음량 종류와 재생 장치 안내](https://support.google.com/android/answer/9082609?hl=ko)처럼 미디어·통화·벨소리 음량이 구분됩니다. 앱을 사용하는 동안 실제 바뀌는 음량을 확인하는 것이 중요합니다.

다른 앱의 오디오도 들리지 않는다면 기기의 출력 설정이나 연결 문제부터 확인합니다. 다른 앱에서는 정상인데 ChatGPT에서만 안 들린다면 사이트·앱의 음소거와 세션 상태를 다시 확인하는 순서로 범위를 좁힐 수 있습니다.

### 마이크 입력 확인

Voice 대화 안의 마이크가 음소거돼 있지 않은지, 이어폰 자체의 물리적 음소거가 켜져 있지 않은지부터 확인합니다. 그다음 앞 절의 앱·사이트·운영체제 권한과 입력 장치를 점검합니다.

Windows 11에서는 **설정 → 시스템 → 소리 → 입력**에서 사용할 마이크를 선택합니다. 장치 속성의 마이크 테스트에서 테스트를 시작하고 짧게 말한 뒤, 중지하고 녹음 샘플을 재생해봅니다. [Microsoft 마이크 문제 해결 안내](https://support.microsoft.com/en-us/windows/fix-microphone-problems-5f230348-106d-bfa4-1db5-336f35576011)에 따른 확인 방법입니다. 여기서부터 소리가 없다면 ChatGPT의 목소리 설정을 바꿀 문제가 아닙니다. 마이크 연결·장치 선택부터 해결해야 합니다.

### 대화 끊김과 주변 소음

스피커 소리나 주변 대화가 마이크로 함께 들어가는지 확인하고, 조용한 장소나 이어폰으로 비교해봅니다. OpenAI는 iPhone에서 대화 중 제어 센터의 **Mic Mode → Voice Isolation**을 사용하는 방법도 안내합니다. 다만 여러 사람이 동시에 이야기하는 상황까지 안정적으로 구분하는 기능으로 생각하면 안 됩니다.

앱을 다시 열거나 웹페이지를 새로고침해도 같은 증상이 이어진다면 [OpenAI 서비스 상태](https://status.openai.com)를 확인합니다. 문의할 때는 기기·OS, 앱 또는 브라우저 버전, Voice 옵션, 화면에 표시된 오류, 다른 앱에서의 마이크·스피커 정상 여부를 정리하면 원인을 좁히는 데 도움이 됩니다. 비밀번호나 대화 속 개인정보는 첨부하지 않습니다.

## Voice 버튼과 사용 제한

현재 설정에는 계정에 따라 **Live·Advanced·Standard**가 표시될 수 있습니다. 이들은 목소리 이름이 아니라 음성대화 방식입니다. ‘Cove로 바꾸기’와 ‘Live로 바꾸기’는 다른 선택입니다.

일반 채팅의 Live는 무료 계정에도 제한적으로 제공되지만, 플랜과 Voice 옵션에 따라 사용 한도가 달라집니다. 한도에 도달하면 ChatGPT의 알림을 확인하고 텍스트로 이어가거나 안내된 시점에 다시 사용하면 됩니다. 마이크 권한을 재설정한다고 사용 한도가 늘어나지는 않습니다.

Voice나 특정 옵션이 보이지 않으면 **로그인 여부 → 앱 업데이트 → 사용 중인 계정·워크스페이스** 순서로 확인합니다. 공식 도움말은 플랜, 지역, 앱 버전, 조직 설정과 자녀 보호 설정이 영향을 줄 수 있다고 설명합니다. 따라서 버튼이 없다는 이유만으로 유료 구독부터 결제할 필요는 없습니다.

## 대화 종료와 개인정보 설정

말을 멈추는 것과 음성대화를 끝내는 것은 다릅니다. 특히 모바일의 **Settings → Voice → Background conversations**를 켜면 다른 앱을 사용하거나 화면을 잠근 상태에서도 대화가 이어질 수 있습니다. 처음 사용할 때는 이 설정을 확인하고, 대화가 끝났다면 종료 제어로 명시적으로 마치는 편이 좋습니다.

녹음과 대화 텍스트의 학습 설정도 구분해야 합니다. OpenAI는 **오디오·비디오 클립은 사용자가 학습용 공유를 선택하지 않는 한 학습에 사용하지 않는다**고 설명합니다. 반면 대화 텍스트 등은 플랜과 ‘Improve the model for everyone’ 설정에 따라 학습에 사용될 수 있습니다. 필요한 경우 **Settings → Data Controls**에서 전체 모델 개선 설정과 오디오 공유 설정을 각각 확인하세요.

처음에는 개인정보 없는 짧은 대화로 시작해 **말 전달, 답변 재생, 종료**를 차례로 확인하면 충분합니다. 그다음 원하는 목소리와 언어를 정하면 됩니다. 문제가 생겼을 때도 ‘마이크가 안 된다’고 한꺼번에 판단하지 말고, 받아쓰기인지 음성대화인지, 입력 문제인지 출력 문제인지 나누면 확인할 설정이 훨씬 분명해집니다.
