### 목차

## 다음에도 쓸 탭 묶음

자료를 찾다 보면 제품 설명, 요금표, 비교 문서가 여러 탭으로 쌓입니다. 오늘은 다른 일을 해야 하지만 내일 같은 자료를 다시 보고 싶다면, 탭을 하나씩 없애는 대신 **탭 그룹을 만들고 `그룹 닫기`를 선택하는 방법**이 있습니다.

여기서 헷갈리는 것이 `그룹 닫기`, `그룹 해제`, `그룹 삭제`입니다. 이름이 비슷하지만 결과는 다릅니다. **나중에 같은 묶음을 다시 열 목적이라면 닫기**, 페이지는 그대로 보고 묶음만 풀 목적이라면 해제입니다. 삭제는 더 이상 그 그룹을 남겨 두지 않을 때 쓰는 선택입니다.

2026년 10월 24일 확인한 [데스크톱 Chrome 공식 도움말](https://support.google.com/chrome/answer/2391819?co=GENIE.Platform%3DDesktop&hl=ko)을 기준으로 설명하겠습니다. 아래 절차는 공식 안내를 정리한 것으로, 이번에 브라우저의 그룹 생성·복원을 직접 실행해 검증한 결과는 아닙니다. 모바일 앱은 메뉴와 배치가 다를 수 있으므로 컴퓨터용 Chrome을 기준으로 읽어 주세요.

## 접기·닫기·해제·삭제의 구분

탭 그룹은 관련 페이지를 이름과 색으로 묶어 두는 기능입니다. 예를 들어 `제품 비교`라는 그룹에 설명 페이지와 요금표를 넣으면, 어느 탭들이 같은 작업에 속하는지 구분하기 쉽습니다.

그룹을 정리할 때는 **화면에서 잠깐 치우려는 것인지, 묶음 자체를 없애려는 것인지** 먼저 정하면 됩니다.

| 하려는 일 | 선택할 동작 | 확인할 결과 |
| --- | --- | --- |
| 지금 열린 탭의 자리만 줄이기 | 그룹 이름을 눌러 접기 | 이름이나 색 원은 남고 그룹 안의 탭 표시가 접힘 |
| 지금은 닫고 나중에 같은 묶음 열기 | 그룹 닫기 | 탭 표시줄에서는 닫히지만 저장된 그룹 목록에서 다시 찾을 수 있음 |
| 페이지는 열어 둔 채 묶음 풀기 | 그룹 해제 | 탭은 열린 상태로 남고 그룹은 삭제됨 |
| 더 이상 필요 없는 묶음 없애기 | 그룹 삭제 | 저장된 그룹을 제거하는 동작이며, 나중에 열기 위한 보관 용도가 아님 |

특히 **접기는 닫기가 아닙니다.** 탭 표시줄에서 제목이 안 보인다고 페이지를 닫은 것은 아닙니다. 이 기능을 사용했다는 이유만으로 메모리가 일정량 줄어든다고 판단할 수도 없습니다. 메모리 절약 설정이 목적이라면 [크롬 메모리 절약과 사이트 예외](/blog/chrome-memory-saver-tabs)를 따로 확인하는 편이 맞습니다.

그룹 해제도 잠시 숨기는 기능이 아닙니다. 공식 도움말은 해제할 때 현재 기기의 탭은 유지되지만 그룹 자체는 삭제된다고 설명합니다. 내일 다시 같은 이름으로 꺼내고 싶다면 해제가 아니라 닫기를 선택하세요.

## 자료조사 탭 묶기와 닫기

처음에는 중요한 업무 페이지 대신 다시 찾아도 되는 공개 페이지 두 개로 경로를 확인하는 편이 좋습니다. 아래 `제품 비교`는 이해를 돕기 위한 그룹 이름 예시입니다.

1. 묶고 싶은 페이지를 컴퓨터용 Chrome에서 엽니다.
2. 웹페이지 안이 아니라 **브라우저의 탭 제목**을 마우스 오른쪽 버튼으로 클릭합니다.
3. `그룹에 탭 추가 → 새 그룹`을 선택합니다.
4. 만들어진 그룹의 이름이나 색깔 있는 원을 마우스 오른쪽 버튼으로 클릭하고 `제품 비교`처럼 용도를 알 수 있는 이름과 색을 정합니다.
5. 두 번째 탭을 해당 그룹으로 드래그하거나, 그 탭의 우클릭 메뉴에서 `그룹에 탭 추가`를 눌러 기존 그룹을 선택합니다.

여기까지 했다면 페이지가 단순히 나란히 열려 있는지보다 **의도한 그룹에 포함되어 있는지**를 확인하세요. 그룹 이름을 눌렀을 때 함께 접히는 탭이 원하는 자료인지 살펴보면 됩니다. 다시 이름을 누르면 펼칠 수 있습니다.

작업을 잠시 멈출 때는 그룹 이름이나 색 원을 우클릭하고 `그룹 닫기`를 선택합니다. 개별 탭의 닫기 버튼을 차례로 누르는 것과 구분해서 사용하세요. 같은 묶음을 보존하려는 상황에서는 공식 도움말이 안내하는 그룹 단위의 닫기 경로가 목적에 맞습니다.

닫기 전에 웹 편집기나 입력 폼의 **저장하지 않은 작업부터 저장**해 두세요. 여기서 보존하려는 것은 다시 찾아 열 탭 묶음입니다. 이를 문서 내용이나 입력 상태의 백업으로 생각하고 작업물을 맡기는 것은 피하는 편이 좋습니다.

## 닫은 그룹 다시 열기

탭 표시줄에서 사라졌다고 바로 그룹이 삭제된 것은 아닙니다. 공식 도움말은 닫힌 그룹이 북마크바 또는 메뉴에 저장되며 다시 열 수 있다고 안내합니다.

가장 먼저 확인할 경로는 Chrome 오른쪽 상단의 `더보기 → 탭 그룹`입니다.

1. 오른쪽 상단의 점 세 개로 된 `더보기` 메뉴를 엽니다.
2. `탭 그룹`으로 이동합니다.
3. 앞에서 정한 `제품 비교` 그룹을 선택합니다.
4. 그룹 이름과 함께 필요한 페이지들이 다시 열리는지 확인합니다.

북마크바에 탭 그룹이 표시되어 있다면 **그리드 아이콘을 누르고 그룹 이름을 선택**하는 경로도 있습니다. 북마크바에 이름이 안 보이는 것과 저장된 그룹이 없는 것은 같은 상황이 아니므로, 우선 `더보기 → 탭 그룹` 목록부터 확인하면 됩니다.

확인의 끝은 그룹 이름이 목록에 보이는 순간이 아닙니다. **그룹을 선택했을 때 필요한 페이지가 열리고, 원하는 자료를 계속 볼 수 있어야 합니다.** 사이트에서 로그인을 다시 요구하거나 문서 접근 권한이 없다고 나오면 그룹 복원과 해당 사이트의 접근 문제를 나눠 확인해야 합니다.

## 그룹이 보이지 않을 때의 확인 순서

그룹을 찾을 수 없을 때 동기화 설정부터 초기화하거나 프로필을 삭제할 필요는 없습니다. 화면 표시, 현재 프로필, 앞서 실행한 동작부터 구분해 보세요.

### 탭 이름 없이 그룹 이름만 남은 경우

그룹이 접혀 있을 수 있습니다. 남아 있는 그룹 이름이나 색 원을 한 번 눌러 펼칩니다. 이 경우에는 저장 목록에서 복원하는 작업이 아니라, 이미 열려 있는 그룹의 표시를 바꾸는 것입니다.

### 북마크바에서만 보이지 않는 경우

`더보기 → 탭 그룹`에서 이름을 찾습니다. 목록에는 있는데 북마크바에서만 찾기 어렵다면 `설정 → 모양`의 `북마크바에 탭 그룹 표시`를 확인합니다. 새 그룹을 북마크바에 계속 올려 두고 싶을 때는 `새 탭 그룹을 북마크바에 자동으로 고정` 설정도 살펴볼 수 있습니다.

이 설정들은 그룹을 찾는 위치와 관련된 선택입니다. 북마크바에 표시하지 않는 것만으로 그룹을 삭제했다고 판단하지 마세요.

### 저장된 그룹 목록에도 없는 경우

먼저 작업하던 Chrome 프로필인지 확인합니다. 업무용과 개인용 프로필을 나누어 쓰고 있다면 다른 창을 보고 있을 수 있습니다. 프로필과 계정의 구분은 [크롬 업무용·개인용 프로필 안내](/blog/chrome-work-personal-profiles)에 정리했습니다.

그다음에는 앞에서 `그룹 닫기` 대신 `그룹 해제`나 `그룹 삭제`를 선택한 것은 아닌지 확인합니다. 해제 후 페이지가 그대로 열려 있다면 필요한 탭들을 다시 새 그룹으로 묶는 방법을 사용할 수 있습니다. 저장된 그룹이 없는데 표시 설정만 바꾸는 것으로 원래 묶음이 되살아나지는 않습니다.

실수로 탭이나 창을 닫은 경우에는 Windows·Linux에서 `Ctrl + Shift + T`, Mac에서 `Command + Shift + T`로 다시 열기를 시도할 수 있습니다. 다만 공식 도움말이 이 단축키에 대해 보장하는 범위는 **닫은 탭이나 창의 다시 열기**입니다. 삭제한 저장 그룹의 이름·구성·동기화 상태까지 원래대로 복구하는 방법으로 생각하지는 마세요.

## 다른 기기와 함께 쓸 때의 주의점

Google은 방문 기록과 탭이 Google 계정과 동기화되는 경우, 탭 그룹의 변경사항도 여러 기기에 자동 저장·동기화된다고 안내합니다. 다른 기기에서 같은 그룹을 쓰려면 Chrome에서 사용하는 계정과 관련 동기화 상태를 함께 확인해야 합니다.

반대로 중요한 자료를 정리할 때는 **그룹 삭제와 그룹 해제를 현재 창에만 영향을 주는 작업으로 생각하지 않는 것**이 중요합니다. 공식 도움말은 두 동작 모두 같은 Google 계정을 사용하는 다른 기기에서도 그룹을 삭제한다고 명시합니다. 동기화를 사용하고 있다면 다른 기기에서 이어 볼 그룹인지 먼저 확인하세요.

예를 들어 노트북에서는 잠시 자료조사를 멈추고 내일 데스크톱에서 이어 볼 계획이라면, 묶음을 없애는 삭제·해제보다 닫기가 의도에 맞습니다. 동기화가 필요한 자료인지, 회사 기기에서 계정에 저장해도 되는 정보인지는 별도로 판단해야 합니다. 그룹을 열기 위해 회사의 관리 정책을 해제하거나 동기화를 무조건 켤 필요는 없습니다.

## 작업을 이어 가기 위한 선택

탭 그룹을 쓸 때 매번 모든 탭을 열어 두어야 하는 것은 아닙니다. `제품 비교`, `보고서 자료`, `다음에 읽기`처럼 다시 시작할 작업의 이름으로 묶고, 당장 쓰지 않는 그룹은 닫아 두는 방식으로 정리할 수 있습니다.

선택 기준은 간단합니다. **다시 같은 묶음으로 쓸 자료는 닫고, 페이지를 보면서 묶음만 풀려면 해제하고, 더 이상 남길 필요 없는 그룹은 삭제합니다.** 첫 그룹은 중요하지 않은 페이지로 닫기와 다시 열기 경로를 확인한 뒤 실제 자료에 적용하는 편을 권합니다.

탭을 옆으로 길게 표시하고 싶은 것이라면 그룹 관리와 별개로 [크롬 세로탭 설정](/blog/chrome-vertical-tabs)을 사용할 수 있습니다. 세로 탭은 표시 위치, 탭 그룹은 자료의 묶음, 프로필은 작업 환경의 구분이라는 차이를 알고 선택하면 설정을 불필요하게 늘리지 않아도 됩니다.
