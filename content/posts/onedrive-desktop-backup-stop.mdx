### 목차

## 들어가며

Windows 바탕 화면의 파일이 OneDrive와 함께 움직이는데, 이 PC에서는 더 이상 바탕 화면을 동기화하고 싶지 않을 수 있습니다. 이때 백업 스위치만 끄면 파일이 양쪽에 그대로 남을 거라고 생각하기 쉽습니다.

Microsoft의 현재 Windows 안내에서는 중지할 때 **OneDrive에만 남기거나 내 PC에만 남기는 선택지**가 나옵니다. 각각 다른 쪽에서는 파일을 제거하는 선택이므로, 먼저 별도 사본을 만들고 원하는 위치를 결정하는 편이 안전합니다.

아래 절차는 2026년 11월 16일 확인한 [Microsoft의 폴더 백업 안내](https://support.microsoft.com/en-us/onedrive/back-up-your-folders-with-onedrive)를 기준으로 정리했습니다. 화면 문구와 선택지는 OneDrive 버전, 계정과 조직 정책에 따라 다를 수 있으니 **실제 대화상자의 결과가 다르거나 불분명하면 진행하지 마세요.**

## 먼저 구분할 저장 위치

OneDrive의 바탕 화면 백업은 Windows 바탕 화면 폴더를 OneDrive와 연결해 파일을 동기화하는 기능입니다. 같은 OneDrive 폴더에서 파일을 변경하거나 삭제하면 연결된 다른 장치와 클라우드에도 그 변경이 반영될 수 있습니다. 다른 PC에도 같은 바탕 화면 항목이 보일 수 있지만, 각각 독립적으로 보관된 백업이라는 뜻은 아닙니다. [동기화 동작에 대한 Microsoft 안내](https://support.microsoft.com/en-us/onedrive/sync-your-computer-s-files-and-folders-with-onedrive)를 참고하세요.

파일 탐색기에 이름이 보인다는 것과 파일 내용이 PC에 내려와 있다는 것도 다릅니다. [Files On-Demand 안내](https://support.microsoft.com/en-us/onedrive/save-disk-space-with-onedrive-files-on-demand-for-windows)에 따르면 파란 구름은 온라인 전용이고, 초록색 테두리의 체크는 로컬에서 사용할 수 있는 파일입니다. 초록색 원 안의 흰 체크는 `항상 이 장치에 유지`로 지정해 내려받은 파일입니다. 온라인 전용 파일은 인터넷이 없을 때 열 수 없습니다.

마지막으로 **동기화 폴더 안의 로컬 파일도 별도의 독립 백업은 아닙니다.** 실수로 삭제한 내용이 동기화될 수 있기 때문입니다. 중지 전에는 OneDrive 동기화 범위 밖의 외장 저장장치 등 별도 위치에 사본을 만들고 열어 확인하세요. 회사 파일이라면 먼저 조직의 저장·보안 정책을 따릅니다.

## 중지 전 준비

1. 작업 중인 파일을 저장하고 닫습니다. 작업 표시줄 오른쪽의 OneDrive 구름 아이콘을 열어 올바른 개인 또는 회사·학교 계정인지, 동기화가 진행 중이거나 오류가 있는지 확인합니다. 여러 계정이 있다면 바꾸려는 바탕 화면이 어느 계정에 연결됐는지 특히 주의하세요.
2. 파일 탐색기에서 현재 바탕 화면과 해당 OneDrive의 바탕 화면 폴더를 살펴봅니다. 같은 이름의 폴더라도 위치와 내용이 다를 수 있습니다. 파일 탐색기의 주소 표시줄과 폴더 속성을 확인하고, 중요한 파일과 하위 폴더를 빠뜨리지 않도록 합니다.
3. 인터넷에 연결하고 PC에 충분한 여유 공간을 확보합니다. OneDrive 쪽 바탕 화면 폴더를 마우스 오른쪽 버튼으로 눌러 `항상 이 장치에 유지`를 선택하고 다운로드가 끝날 때까지 기다립니다. 하위 항목에도 온라인 전용 표시나 오류가 남았는지 확인하세요. 용량이 부족하거나 동기화가 멈추면 해결하기 전에는 중지하지 않습니다.
4. 내려받은 중요한 파일과 하위 폴더를 OneDrive 동기화 범위 밖의 별도 저장장치나 폴더에 **이동이 아닌 복사**로 보관합니다. 복사 대상도 실제 경로를 확인하세요. OneDrive 밖이라고 생각한 폴더가 동기화 범위 안이면 독립 사본이 아닙니다.
5. 복사한 위치에서 중요한 문서·사진 등 몇 개를 직접 열고, 하위 폴더와 파일 수·크기를 원본과 비교합니다. 클라우드에만 있던 항목도 빠지지 않았는지 확인하세요. 열리지 않거나 누락됐다면 원본을 지우거나 다음 단계로 넘어가지 않습니다.

Microsoft는 중지하려는 폴더에 온라인 전용 파일이 있으면 일부 파일을 옮길 수 없다는 메시지가 나타날 수 있으며, `항상 이 장치에 유지`로 다운로드하라고 안내합니다. 녹색 표시가 나타나기 전이나 오류가 남은 상태에서 완료된 것으로 판단하지 마세요.

## 바탕 화면 백업 중지

별도 사본을 확인했다면 다음 경로에서 바탕 화면만 선택합니다.

1. 작업 표시줄의 OneDrive 구름 아이콘을 선택합니다. 보이지 않으면 알림 영역의 숨겨진 아이콘도 확인합니다.
2. `도움말 및 설정`의 톱니바퀴에서 `설정`을 엽니다.
3. `동기화 및 백업`에서 `백업 관리`를 선택합니다.
4. `바탕 화면`의 백업 스위치를 끕니다. 문서나 사진까지 함께 중지하려는 것이 아니라면 해당 스위치는 그대로 둡니다.
5. 표시되는 보관 위치와 제거 결과를 읽고, 아래 기준에 맞는 선택지를 고른 뒤 화면의 안내에 따라 확인합니다.

| 원하는 결과 | Microsoft 안내의 선택 | 확인할 결과 |
| --- | --- | --- |
| 이 PC의 바탕 화면에 파일을 남기고 OneDrive에서는 제거 | `내 PC에만 파일 유지`에 해당하는 선택 | 파일이 PC에 남고 OneDrive에서는 제거됩니다. 다른 장치에서도 클라우드 파일을 이용해야 한다면 선택 전 영향을 고려하세요. |
| OneDrive에 파일을 남기고 이 PC에서는 제거 | `OneDrive에만 파일 유지`에 해당하는 선택 | 파일이 OneDrive에 남고 이 컴퓨터에서는 제거됩니다. 이 PC의 바탕 화면에 그대로 남는 선택이 아닙니다. |
| 양쪽에 각각 파일을 보관 | 위 두 선택 중 어느 것도 양쪽 유지를 약속하지 않음 | 먼저 별도 사본을 확인하고, 원하는 위치에 사본을 추가한 뒤 각각 확인합니다. 두 사본은 이후 자동으로 같은 내용이 되지 않습니다. |

표현은 화면 언어에 따라 다를 수 있습니다. 특히 두 번째 선택은 `백업만 중지하고 PC에는 그대로 둔다`는 뜻이 아닙니다. **원하는 결과와 화면 설명이 일치하지 않거나 선택지가 보이지 않으면 취소하고** [공식 안내](https://support.microsoft.com/en-us/onedrive/back-up-your-folders-with-onedrive)를 다시 확인하세요. 회사·학교에서 관리하는 계정은 관리자가 알려준 절차를 따르고, 변경이 막혀 있다면 정책을 우회하지 말고 IT 관리자에게 문의합니다.

## 중지 후 파일 확인

중지 버튼을 눌렀다는 사실만으로 끝내지 말고, 선택한 위치에서 파일을 직접 확인합니다.

- `백업 관리`를 다시 열어 바탕 화면의 백업이 꺼져 있는지 확인합니다. OneDrive 전체 연결 해제나 문서·사진 백업 중지와는 별개입니다.
- **PC에만 유지**를 골랐다면 현재 Windows 바탕 화면 폴더에서 중요한 파일과 하위 폴더가 보이는지, 몇 개가 실제로 열리는지 확인합니다. 해당 OneDrive 계정의 웹에서도 제거 결과를 확인하고, 다른 기기에서 필요한 파일이 없는지 살펴보세요.
- **OneDrive에만 유지**를 골랐다면 해당 계정의 OneDrive 웹에서 바탕 화면 폴더와 중요한 파일을 확인합니다. 이 PC의 바탕 화면이 비어 보이더라도 바로 삭제됐다고 결론 내리지 말고, OneDrive와 앞에서 만든 별도 사본을 확인하세요.
- 어느 쪽을 골랐든 중지 전 만든 별도 사본도 다시 열어봅니다. 앞으로 PC의 바탕 화면에 새로 저장할 파일은 중지한 바탕 화면 백업으로 자동 보호되지 않으므로, 필요한 파일을 어디에 백업할지 따로 정하세요.

중지 후 PC와 클라우드 양쪽에 파일이 필요하다면, 먼저 남아 있는 원본과 별도 사본을 확인한 후 필요한 파일을 원하는 위치에 **복사**합니다. PC에 둘 때는 현재 바탕 화면 폴더의 실제 경로가 OneDrive 동기화 범위 밖인지 확인하세요. 같은 이름의 파일이 있으면 무턱대고 덮어쓰지 말고 내용과 수정 시각을 비교합니다. 복사 후에는 PC와 웹에서 각각 파일을 열어 확인하고, 이후 변경 사항이 두 사본 사이에 자동 반영된다고 가정하지 마세요.

## 파일이 보이지 않을 때

우선 추가 삭제나 대량 이동을 멈추고, 현재 바탕 화면 폴더의 경로, 해당 계정의 OneDrive 폴더와 웹, 중지 전 만든 별도 사본을 차례로 확인합니다. 동기화 오류나 다운로드 미완료 표시가 있으면 오류를 먼저 살펴보세요. 위치가 확인되지 않은 상태에서 폴더를 정리하면 남은 원본까지 잃을 수 있습니다.

삭제가 의심되면 [OneDrive 웹 휴지통과 Windows 휴지통](https://support.microsoft.com/en-us/onedrive/restore-your-onedrive-files)을 확인하고 필요한 항목을 복원합니다. 온라인 전용 파일을 삭제했다면 PC 휴지통에는 없을 수 있습니다. OneDrive 휴지통의 보존 기간은 계정과 관리자 설정에 따라 다르고, 영구 삭제된 항목은 복원할 수 없으므로 휴지통을 독립 백업으로 여기지 마세요. 회사·학교 계정이거나 복원할 파일이 보이지 않으면 관리자에게 문의하는 편이 안전합니다.

참고로 OneDrive 설정의 `계정 → 폴더 선택`은 이 PC에 동기화할 OneDrive 폴더를 고르는 별도의 기능입니다. [Microsoft 안내](https://support.microsoft.com/en-us/onedrive/choose-which-onedrive-folders-you-want-to-sync-on-windows-or-macos)에 따르면 선택을 해제한 폴더는 PC에서 제거되고 온라인에는 남으며, 바탕 화면 같은 중요 폴더는 선택 해제가 제한될 수 있습니다. 바탕 화면 백업을 끄기 위한 대체 경로로 혼동하지 마세요.
