엑셀 수식을 ChatGPT에 물어본 뒤 답을 복사해 붙여넣는 대신, **엑셀 안에서 ChatGPT에게 셀과 표를 수정해달라고 요청**할 수 있습니다. 이때 사용하는 제품은 OpenAI의 공식 추가 기능인 **ChatGPT for Excel**입니다. 엑셀 오른쪽의 대화 패널에서 현재 통합 문서를 읽고, 수식을 설명하거나 시트를 수정하는 방식입니다.

설치할 때는 이름보다 게시자를 먼저 보세요. Microsoft Marketplace에서 앱 이름은 `ChatGPT`, 게시자는 **OpenAI, LLC**입니다. Microsoft Copilot이나 이름이 비슷한 다른 회사의 GPT 추가 기능을 설치하는 절차가 아닙니다.

이 글은 2026년 10월 6일 확인한 공식 안내를 바탕으로 한 사용법입니다. 추가 기능 설치·로그인 후의 AI 편집은 직접 실행하지 않았습니다. 대신 아래 연습 데이터와 검산용 수식·표는 **실제 Microsoft Excel에서 계산하고 캡처**했습니다. 화면은 ChatGPT의 실행 결과가 아니라, 요청 후 무엇을 확인해야 하는지 보여주는 비교 기준입니다.

## 공식 추가 기능과 지원 환경

ChatGPT for Excel은 [OpenAI 도움말](https://help.openai.com/en/articles/20001063-chatgpt-for-excel-and-google-sheets)에서 안내하는 **Excel 내부의 사이드바형 추가 기능**입니다. ChatGPT 웹사이트에 `.xlsx`를 업로드해 분석하거나 수정된 파일을 내려받는 작업과는 다릅니다.

| 구분 | 작업 위치와 확인할 항목 |
| --- | --- |
| ChatGPT for Excel | Excel의 ChatGPT 패널, 게시자 OpenAI, LLC, ChatGPT 계정으로 로그인 |
| Microsoft Copilot | Microsoft가 제공하는 Excel의 Copilot 기능, 별도의 이용 조건 적용 |
| 제3자 GPT 추가 기능 | 각 회사가 제공하는 앱, API 키·구독·데이터 처리 조건을 별도로 확인 |
| ChatGPT 파일 업로드 | ChatGPT 대화에 파일을 첨부하는 방식, 열려 있는 Excel에 추가 기능을 설치하는 것과 다름 |

[Microsoft의 Copilot 안내](https://support.microsoft.com/en-us/excel/copilot/get-started-with-copilot-in-excel) 역시 통합 문서 편집을 지원하지만, 같은 제품은 아닙니다. Copilot 버튼이 보인다는 이유로 ChatGPT가 연결된 것은 아니며, 이 글의 절차에 Copilot 구독이나 OpenAI API 키를 끼워 넣을 필요도 없습니다.

### 웹과 데스크톱

OpenAI는 **데스크톱 Excel과 웹용 Excel**의 설치 경로를 안내합니다. [Microsoft 설치 페이지](https://store.office.com/addinsinstallpage.aspx?assetid=WA200010215)의 호환 목록에는 Windows용 Excel 2013 이상, Mac용 Excel 2016 이상, 웹용 Excel이 표시되어 있습니다.

다만 이 목록만으로 오래된 영구 라이선스 버전에서 모든 기능이 동작한다고 판단하지는 마세요. Marketplace도 실제 접근이 Microsoft 365 환경·관리자 정책 등에 따라 달라질 수 있다고 명시합니다. 처음 시작한다면 업데이트된 데스크톱 Excel이나 웹용 Excel에서 확인하고, 앱을 찾을 수 없거나 시작되지 않으면 설치 화면의 호환 안내와 회사의 추가 기능 정책부터 확인하는 편이 좋습니다. 모바일 Excel을 이 절차의 지원 대상으로 가정하지 않습니다.

### 플랜과 사용 한도

현재 영문 도움말 기준으로 Free·Go·Plus·Pro·Business·Enterprise·Edu·K-12에 전 세계 제공됩니다. 따라서 유료 플랜만 쓸 수 있는 베타라는 예전 안내를 현재 조건으로 읽을 필요는 없습니다. 다만 실제 계정의 접근 권한과 조직 정책은 별도로 적용됩니다. 일부 한국어 소개 페이지에는 베타·유료 플랜 중심의 문구가 남아 있어, 여기서는 **최신 영문 도움말과 Marketplace의 일반 제공 안내**를 기준으로 삼았습니다.

- **Free·Go:** 제한된 사용량이 포함됩니다. 무료라고 무제한은 아닙니다.
- **Plus·Pro:** 플랜의 에이전트형 작업 사용 한도가 적용되며, 지원되는 다른 기능과 한도를 공유할 수 있습니다.
- **조직 플랜:** 플랜별 크레딧·사용 조건과 관리자 제어를 확인해야 합니다. 2026년 6월 2일까지였던 무료 미리보기를 현재의 무제한 혜택으로 생각하면 안 됩니다.

[개인 플랜 크레딧 안내](https://help.openai.com/en/articles/12642688-using-credits-for-flexible-usage-in-chatgpt-personal-plans)는 포함 사용량을 먼저 쓰고, 한도를 넘으면 보유 크레딧을 사용하는 구조를 설명합니다. 작업 크기와 모델, 입력·출력량에 따라 사용량이 달라지므로 ‘수식 한 번 수정에 고정 요금’으로 계산할 수는 없습니다. 시작 전 **ChatGPT 설정의 Usage**에서 한도·잔액·자동 충전 여부를 확인하세요. ChatGPT 이용 크레딧은 API 크레딧과도 다릅니다. Excel 자체의 이용 권한 역시 별도로 필요합니다.

## 추가 기능 설치와 로그인

개인 정보가 없는 새 통합 문서부터 준비합니다. 이미 중요한 파일을 열었다면 복사본을 저장하고, 원본이 아닌 연습용 문서에서 시작하세요.

1. Excel에서 **홈 → 추가 기능**을 엽니다. 영문 메뉴는 **Home → Add-ins**입니다.
2. `ChatGPT`를 검색합니다.
3. 게시자가 **OpenAI, LLC**인지 확인합니다. [공식 Marketplace 등록 페이지](https://marketplace.microsoft.com/en-us/product/office/WA200010215)와 대조하면 이름이 비슷한 앱을 피할 수 있습니다.
4. 문서를 읽고 변경할 수 있으며 인터넷으로 데이터를 보낼 수 있다는 권한 설명을 읽습니다. 개인·회사 정책상 허용되는 경우에만 추가합니다.
5. 설치 후 통합 문서 위쪽 리본에서 **ChatGPT**를 열고, 사용할 **ChatGPT 계정**으로 로그인합니다. Excel에 로그인한 Microsoft 계정과 ChatGPT 계정은 구분하세요.
6. 현재 문서 옆에 ChatGPT 패널과 메시지 입력창이 열리는지 확인합니다. 첫 요청은 아래처럼 변경 없는 확인 작업으로 시작합니다.

```text
아직 셀을 수정하지 마세요.
현재 통합 문서의 시트 이름과 지금 선택된 시트를 알려주세요.
선택된 시트가 비어 있으면 빈 시트라고 설명하세요.
읽을 수 없다면 데이터를 추측하지 말고 이유를 알려주세요.
```

패널이 열렸다는 것만으로 연결 확인이 끝난 것은 아닙니다. **실제 시트 이름과 빈 시트 여부를 맞게 읽는지**까지 확인해야 다른 문서를 대상으로 작업하는 실수를 줄일 수 있습니다.

회사 계정에서 앱을 추가할 수 없다면 우회 설치부터 시도하지 마세요. Microsoft 365의 추가 기능 배포 정책과 ChatGPT 워크스페이스 권한은 서로 다른 확인 대상입니다. OpenAI는 관리자가 `Workspace settings → Permissions & roles → ChatGPT for Excel and Google Sheets`에서 기능을 허용하는 경로를 안내합니다. Microsoft Store 접근이 막힌 조직에는 관리자용 배포 방법도 있으므로 담당자에게 공식 도움말을 전달하는 편이 안전합니다.

## 연습용 매출 데이터

첫 작업은 `수량 × 단가 × (1 − 할인율)`로 계산하는 작은 매출표로 해보겠습니다. 새 시트 이름을 `매출연습`으로 바꾸고, 아래 내용을 복사해 **A1**에 붙여넣으세요. 열 사이는 탭으로 구분되어 있습니다. E열은 제목만 있고 계산 값은 비어 있습니다.

```text
상품	수량	단가	할인율	매출
노트	3	2000	10%
펜	5	1000	0%
파일	2	3000	5%
```

여기서 `A1:E4`는 A1부터 E4까지의 사각형 영역입니다. 할인율은 `10`이 아니라 `10%`로 입력합니다. 화면에 숫자가 보인다고 모두 계산 가능한 숫자인 것은 아니므로, 붙여넣은 값에 작은따옴표나 공백이 섞이지 않았는지도 확인하세요.

## 범위를 정한 수식 수정

### 변경 계획 요청

ChatGPT 패널에서 먼저 **어느 셀을 어떻게 바꿀지** 묻습니다. 가능하면 `@`로 대상 시트를 지정하고, 문장에도 시트명과 범위를 함께 적습니다.

```text
매출연습 시트만 확인하세요. 아직 수정하지 마세요.
A1:E4에서 B열은 수량, C열은 단가, D열은 할인율입니다.
E2:E4에 수량 × 단가 × (1 - 할인율) 수식을 넣으려고 합니다.
수정할 범위와 각 행에 넣을 수식을 먼저 알려주세요.
A1:D4의 원본 값과 다른 시트는 바꾸지 마세요.
```

계획에서 E2가 `=B2*C2*(1-D2)`를 참조하는지 확인합니다. 다음 행은 B3·C3·D3, 그다음 행은 B4·C4·D4를 참조해야 합니다. 할인율이 이미 백분율인데 다시 100으로 나누거나, 모든 행이 첫 번째 상품만 참조하는 제안은 적용하지 않습니다.

### 수식 적용 요청

계획이 맞으면 다음처럼 적용 범위를 다시 적어 요청합니다.

```text
확인한 계획대로 매출연습!E2:E4에 수식을 입력하세요.
계산된 숫자만 넣지 말고 원본 셀을 참조하는 Excel 수식을 사용하세요.
E2:E4는 천 단위 구분 기호가 있는 정수 형식으로 표시하세요.
A1:D4와 다른 시트는 그대로 두고, 끝나면 변경한 셀 주소를 알려주세요.
```

공식 안내는 변경 전 권한을 요청하고 참조·수정한 셀을 연결해 보여주는 흐름을 설명합니다. 승인 화면이 나오면 **대상 시트와 변경 범위가 계획과 같은지** 확인한 뒤 진행하세요. 버튼 이름이나 승인 횟수가 모든 버전에서 같다고 가정하지 말고, 셀이 실제로 바뀌는지도 함께 살펴봅니다.

### 수식과 값 대조

응답에 ‘완료’가 적혔다는 것만 보지 말고 E2를 클릭해 **수식 입력줄**을 확인합니다. `5400`이라는 고정 숫자가 아니라 `=B2*C2*(1-D2)`처럼 `=`로 시작하는 수식이 있어야 합니다. 같은 계산을 하는 구조적 참조 수식도 가능하지만, 원본 수량·단가·할인율을 사용하는지는 확인해야 합니다.

이 예제의 검산 값은 E2가 **5,400**, E3가 **5,000**, E4가 **5,700**입니다. 세 값은 실제 Excel 계산으로 확인했습니다.

## Excel 표와 합계 행

셀에 색만 칠하는 것과 **Excel의 표 기능**으로 바꾸는 것은 다릅니다. 표로 만들면 머리글에 필터가 생기고, 표 이름과 열 이름을 이용해 수식을 관리할 수 있습니다. 다음 요청에서는 이 차이를 분명히 적습니다.

```text
매출연습!A1:E4를 머리글이 있는 Excel 표로 변환하세요.
단순히 색만 칠하지 말고 표 이름은 SalesPractice로 지정하세요.
같은 이름의 표가 이미 있으면 임의로 덮어쓰지 말고 알려주세요.
원본 값과 매출 수식은 유지하고, 줄무늬가 있는 표 스타일을 적용하세요.
표의 요약 행을 켜고 매출 열에 합계를 표시하세요.
다른 셀과 시트는 수정하지 말고 변경 범위를 요약하세요.
```

**A5:E5가 비어 있는지 먼저 확인**하세요. 합계 행이 생기면 기존 A1:E4보다 한 행 넓은 영역을 사용합니다. 요청 자체가 좁아 보여도 주변 셀을 덮어쓸 수 있는 지점을 확인하는 습관이 필요합니다.

작업 후에는 다음을 대조합니다.

- 표 안의 셀을 선택했을 때 **테이블 디자인** 메뉴에서 표 이름이 `SalesPractice`인지 확인합니다.
- 머리글에 필터 버튼이 있고, 행마다 지정한 스타일이 적용되어 있는지 봅니다.
- 매출 열의 수식이 살아 있고, 요약 행의 전체 합계가 **16,100**인지 확인합니다.
- 다른 데이터나 시트가 새로 생기거나 삭제되지 않았는지 변경 요약과 비교합니다.

위 검산용 표의 요약 행에는 `=SUBTOTAL(109,[매출])`이 들어 있습니다. 이는 필터로 숨긴 행을 제외하고 매출을 더하는 방식입니다. 필터가 켜져 있으면 합계가 16,100보다 작아도 곧바로 오류라고 볼 수 없습니다. **필터를 해제한 전체 합계인지, 현재 보이는 행의 합계인지** 먼저 구분하세요.

색이나 숫자 형식만 다듬고 싶을 때는 표 전체를 다시 만들라고 요청하기보다 `SalesPractice의 단가와 매출 표시 형식만 바꾸고 값·수식·표 범위는 유지하세요`처럼 수정 대상을 더 좁히는 편이 좋습니다.

## 되돌리기와 오류 확인

수식·표·정렬·행 삭제를 한꺼번에 맡기면 무엇 때문에 결과가 바뀌었는지 찾기 어렵습니다. 한 작업씩 적용하고 확인한 뒤 다음 요청으로 넘어가세요.

잘못 바뀌었다면 먼저 추가 요청을 멈춥니다. 패널의 되돌리기 기능이 제공되면 해당 변경을 되돌리고, 셀 값과 수식을 다시 확인합니다. 일반 Excel의 실행 취소가 모든 추가 기능 편집에 그대로 적용된다고 믿지는 마세요. 되돌리기가 제공되지 않거나 원복 여부가 불분명하면 **작업 전 저장한 복사본으로 돌아가는 것이 확실한 복구 기준**입니다. 자동 저장이 켜진 문서는 창을 닫기만 해서는 원상복구되지 않습니다.

| 증상 | 확인 순서 |
| --- | --- |
| 추가 기능 검색에 안 나옴 | 공식 등록 페이지의 게시자 확인 → Excel 환경 확인 → 조직의 Store·추가 기능 정책 문의 |
| 로그인 뒤 권한이 없다고 표시 | 로그인한 ChatGPT 계정·워크스페이스 확인 → 플랜·관리자 허용 상태 확인 |
| 회사 SSO에서 `ADD-IN ERROR` 발생 | 오류 문구를 관리자에게 전달하고 공식 도움말의 SSO 항목 확인. 임의로 보안 설정을 끄지 않기 |
| `#VALUE!` 표시 | 수량·단가·할인율이 텍스트인지, 공백이나 잘못된 참조가 있는지 확인 |
| 결과 숫자는 맞지만 입력 변경에 반응하지 않음 | 고정 숫자를 넣었는지 수식 입력줄 확인. 수식이면 계산 옵션과 참조 범위 확인 |
| 합계가 예상보다 작음 | 표 필터와 숨긴 행, 합계 수식의 범위 확인 |
| 사용 한도 도달 | Usage에서 공유 한도·크레딧 확인. 추가 결제 대신 초기화 시점까지 기다릴지 결정 |

원인을 설명받을 때도 범위를 지정합니다. 예를 들어 `매출연습!E2의 오류를 설명하고 관련 참조 셀을 알려주세요. 아직 수정하지 마세요`라고 요청하면, 오류 확인과 변경 승인을 나누기 쉽습니다. VBA·매크로 같은 고급 기능이나 큰 통합 문서는 일부 기능이 지원되지 않거나 결과가 불완전할 수 있으므로 작은 표의 성공을 전체 업무 자동화로 확대하지 않는 편이 좋습니다.

## 데이터 전송과 최종 확인

**Excel 안에 패널이 있다고 해서 데이터가 내 PC 안에서만 처리되는 것은 아닙니다.** Marketplace는 문서 읽기·변경과 인터넷 전송 권한을 명시합니다. OpenAI 도움말도 응답을 위해 프롬프트·첨부 파일·관련 스프레드시트 문맥을 처리하며, 일부 로그가 안전성과 무결성 목적으로 OpenAI에 30일간 보관될 수 있다고 설명합니다.

또한 Marketplace는 기능 제공을 위해 일부 데이터가 Microsoft와 OpenAI에 공유될 수 있고, ChatGPT의 데이터 학습 설정을 따른다고 안내합니다. 회사 자료라면 조직의 AI 사용 정책과 해당 워크스페이스의 데이터 조건을 먼저 확인하세요. `E열만 바꿔주세요`는 편집 요청이지 **나머지 열을 절대로 읽거나 전송하지 못하게 하는 보안 설정**은 아닙니다.

추가 기능의 대화는 일반 ChatGPT 대화 기록과 별도로 동작하고 메모리도 공유되지 않습니다. 다른 채팅에서 정한 업무 규칙을 이미 알고 있을 것이라고 기대하지 말고, 이번 문서에서 지킬 규칙을 요청에 적어주는 편이 좋습니다.
