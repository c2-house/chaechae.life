### 목차

## 들어가며

회사 메일을 열려는데 개인 계정이 먼저 나오거나, 업무 화면을 공유할 때 개인 북마크가 함께 보이면 신경이 쓰입니다. 창을 하나 더 열고 이름만 업무용으로 붙이면 해결될 것 같지만, **계정과 브라우저 정보를 나누려면 창이 아니라 Chrome 프로필을 따로 만드는 편이 맞습니다.**

프로필은 북마크, 방문 기록, 비밀번호, 설정 등을 나눠 관리하는 단위입니다. 다만 프로필 이름을 다르게 정했다고 Google 계정에 저장한 정보까지 자동으로 분리되는 것은 아닙니다. 프로필을 만든 다음에는 어떤 계정으로 Chrome에 로그인했는지, 어떤 정보를 계정에 저장하는지도 확인해야 합니다.

이 글은 2026년 10월 15일 확인한 **데스크톱 Chrome 공식 도움말을 바탕으로 한 설정 안내**입니다. 이미 섞인 데이터를 삭제하거나 옮기는 대신, 기존 프로필을 그대로 두고 업무용 환경을 추가하는 순서로 설명합니다. 본문의 이미지는 실제 설정 완료 화면이 아니라 해당 조건을 확인한 공식 도움말 캡처입니다.

## 탭 정리와 프로필 분리

먼저 불편한 것이 탭의 개수인지, 로그인 계정인지 구분하면 설정이 간단해집니다.

| 하고 싶은 일 | 먼저 선택할 기능 |
| --- | --- |
| 같은 계정으로 읽는 자료를 주제별로 묶기 | 탭 그룹 |
| 열려 있는 탭 제목을 옆으로 길게 보기 | 세로 탭 |
| 업무용과 개인용 북마크·기록·웹사이트 이용 환경 나누기 | 별도 Chrome 프로필 |
| 다른 사람의 PC를 잠깐 빌려 사용하기 | 신뢰할 수 있는 기기의 게스트 모드 |

탭 그룹의 이름을 `업무`와 `개인`으로 정하는 것은 페이지를 정리하는 방법입니다. 다른 사용자 환경을 만드는 작업은 아닙니다. 세로 탭 역시 탭 표시줄의 위치를 바꿉니다. 탭 배치만 바꾸려는 경우에는 [크롬 세로탭 설정 방법](/blog/chrome-vertical-tabs)으로 충분합니다.

반대로 업무 메일과 개인 메일을 계속 번갈아 쓰고 북마크도 다르게 두고 싶다면 프로필을 나누세요. 처음에는 `개인`과 `업무`처럼 용도가 분명한 두 개면 됩니다. 프로젝트마다 프로필을 만들면 어느 창에 어떤 자료가 있는지 찾는 일이 다시 늘어날 수 있습니다.

## 업무용 프로필 추가와 전환

기존 프로필에 개인 자료가 있다면 그대로 두고 새 업무용 프로필을 만듭니다. 이름을 바꾸는 것만으로 기존 자료가 새 프로필로 이동하지는 않으므로, 처음부터 삭제나 전체 가져오기를 할 필요는 없습니다.

1. 컴퓨터에서 Chrome을 열고 **주소 표시줄이 있는 브라우저 상단의 프로필 아이콘**을 선택합니다. Gmail 웹페이지 안의 계정 사진과는 다른 위치입니다.
2. `Chrome 프로필 추가`를 선택합니다.
3. Google 계정으로 Chrome에 로그인할지 결정합니다. 이 PC에서만 별도 환경을 쓰려면 계정 로그인 없이 시작하는 선택지를 사용하고, 다른 기기에서도 업무 정보를 가져와야 한다면 사용할 업무 계정을 먼저 확인합니다.
4. 이름과 색상을 정합니다. 예를 들어 기존 프로필은 `개인`, 새 프로필은 `업무`로 구분하고 색도 다르게 두면 창을 고르기 쉽습니다. Chrome에 로그인한 경우 처음 이름은 계정 이름으로 설정될 수 있습니다.
5. 새 창의 상단 프로필 메뉴를 열어 현재 선택한 프로필을 확인한 뒤 업무 사이트를 엽니다.

<Image src="/chrome-work-personal-profiles/01-profile-help.png" alt="Chrome 공식 도움말의 새 프로필 추가와 다른 프로필 전환 안내" caption="프로필 추가는 웹사이트의 계정 메뉴가 아니라 Chrome 상단의 프로필 메뉴에서 시작합니다. Google Chrome 도움말, 2026년 10월 15일 확인." />

출처: [여러 프로필로 Chrome 관리하기](https://support.google.com/chrome/answer/2364824?hl=ko)

프로필 전환도 같은 위치에서 합니다. 상단 프로필 아이콘을 누르고 전환할 프로필을 선택하세요. 처음 실행할 때 선택 화면을 보고 싶다면 `프로필 → 기타 Chrome 프로필 → Chrome 프로필 관리`에서 `시작 시 표시`를 선택할 수 있습니다.

이름이나 색상이 비슷해서 헷갈린다면 현재 프로필 메뉴의 `프로필 맞춤설정`에서 바꿀 수 있습니다. 회사가 관리하는 PC나 브라우저에서 추가·로그인 메뉴가 제한되어 있다면 임의로 정책을 해제하지 말고 관리자에게 업무용 프로필 사용 기준을 확인하세요.

## 웹사이트 로그인과 Chrome 로그인

여기서 가장 헷갈리기 쉬운 부분이 로그인입니다. `업무`라는 프로필 안에서 Gmail에 로그인하는 것과, Chrome 자체에 Google 계정으로 로그인하는 것은 구분해야 합니다.

**웹사이트 로그인**은 그 사이트를 어떤 계정으로 이용할지 정하는 일입니다. 업무 프로필에서도 개인 계정으로 웹사이트에 로그인하면 그 사이트에는 개인 자료가 보입니다. 프로필 이름이 사이트의 로그인 계정을 강제로 바꿔 주지는 않습니다.

**Chrome 로그인**은 북마크·비밀번호·설정 등의 정보를 Google 계정에 저장하고 다른 기기에서 가져오는 기능과 연결됩니다. [공식 로그인 도움말](https://support.google.com/chrome/answer/185277?hl=ko)에 따르면 Gmail 같은 서비스에 로그인한 뒤 Chrome에도 로그인할지 묻는 메시지가 표시될 수 있으며, Chrome 로그인은 선택사항입니다.

그래서 메일에 로그인한 뒤 뜨는 안내는 무조건 다음으로 넘기지 않는 편이 좋습니다. 지금 웹사이트만 이용하려는 것인지, 이 프로필의 브라우저 정보도 그 계정에 저장하려는 것인지 보고 선택하세요.

예를 들어 개인 Google 계정으로 Chrome에 로그인해 둔 상태에서 프로필 이름만 `업무`로 바꾸면, 이름은 업무용이어도 계정에 연결된 정보는 개인용일 수 있습니다. **이름과 색은 구별 표시이고, 계정 저장 범위를 대신하는 설정은 아닙니다.**

## Google 계정에 저장할 정보 확인하기

여러 기기에서 같은 북마크를 쓰는 것은 편리합니다. 하지만 업무와 개인 정보를 나누려는 상황에서는 무엇을 어느 계정에 저장하는지가 더 중요합니다.

현재 공식 도움말의 확인 경로는 다음과 같습니다.

1. 확인할 프로필의 창에서 오른쪽 상단 `더보기 → 설정`을 엽니다.
2. `내 Google 서비스 설정`을 선택합니다.
3. 표시된 계정 이름을 확인하고 선택합니다.
4. Google 계정에 저장할 항목을 살펴봅니다. 방문 기록과 열린 탭을 다른 기기와 이어 쓰려면 별도로 `방문 기록 및 탭` 설정도 확인합니다.

<Image src="/chrome-work-personal-profiles/02-account-storage.png" alt="Google 계정에 저장할 정보 선택 경로를 설명하는 Chrome 공식 도움말" caption="프로필 이름뿐 아니라 현재 계정과 계정에 저장할 항목을 확인해야 합니다. Google Chrome 도움말, 2026년 10월 15일 확인." />

출처: [모든 기기에 북마크, 비밀번호 등 가져오기](https://support.google.com/chrome/answer/165139?hl=ko)

Chrome에 로그인하지 않은 상태에서 새로 저장하는 북마크 등의 정보는 기기에 남습니다. 다른 기기에서도 그 정보를 쓰려면 Google 계정에 저장해야 합니다. 이미 계정에 저장한 정보가 로그아웃만으로 삭제되는 것은 아닙니다. 업무·개인 환경을 나누려는데 양쪽에서 같은 Google 계정의 저장 정보를 가져오면, 기대했던 정보 분리와는 달라질 수 있습니다.

저라면 다음처럼 용도부터 정하겠습니다.

- 개인 정보를 여러 기기에서 쓰고 싶다면 개인 프로필에서 개인 Google 계정을 확인합니다.
- 회사 정보를 여러 기기에서 써야 한다면 회사의 허용 범위를 확인한 뒤 업무 계정을 사용합니다.
- 특정 PC에서만 필요한 별도 환경이라면 Chrome 로그인 없이 시작하고, 필요한 웹사이트 로그인만 따로 진행합니다.

마지막 방법도 웹사이트로 보내는 정보를 막는 기능은 아닙니다. Chrome 계정 저장을 사용하지 않는다는 뜻이지, 웹사이트 로그인이나 파일 업로드까지 로컬 작업으로 바뀐다는 뜻은 아닙니다.

## 분리 상태 확인과 잘못 열린 계정 점검

프로필을 만들었다면 실제 자료를 정리하기 전에 작은 확인부터 해보세요. 아래는 기존 데이터를 지우지 않는 확인 절차입니다.

1. `업무` 프로필에서 공개 페이지 하나를 열고 `업무 확인용`이라는 북마크를 추가합니다. 고객 문서나 회사 내부 주소 대신 공개 페이지로 확인하면 됩니다.
2. 상단 프로필 메뉴에서 `개인` 프로필로 전환합니다. 이름과 색상이 달라지는지, 방금 만든 북마크가 어느 쪽에 나타나는지 확인합니다.
3. 두 프로필에서 각각 사용할 웹사이트를 열고 사이트 안의 계정 메뉴를 확인합니다. 브라우저 프로필 이름과 별개로, 실제 로그인된 이메일이나 조직이 의도한 것인지 봅니다.
4. 업무 창을 닫았다가 프로필 메뉴로 다시 열어 봅니다. 업무용 북마크를 다시 찾을 수 있는지 확인합니다. 웹사이트 로그인은 해당 서비스의 세션 정책에 따라 다시 요구될 수 있습니다.

**완료 기준은 창이 두 개 떠 있는 것이 아니라, 의도한 프로필에서 의도한 자료와 사이트 계정이 보이는 것입니다.** 같은 계정에 저장한 정보를 양쪽에서 가져오고 있다면 북마크가 양쪽에 보일 수 있으니, 이 확인을 보안 격리 시험으로 받아들이지는 마세요.

원하지 않는 계정이 보인다면 프로필을 삭제하기 전에 다음 순서로 확인합니다.

| 관찰한 상황 | 먼저 확인할 곳 |
| --- | --- |
| 창 이름만 다르고 북마크도 똑같음 | 상단 프로필 메뉴에서 실제로 다른 프로필인지 확인 |
| 업무 프로필인데 개인 메일이 열림 | 메일 웹사이트 안의 로그인 계정 확인 |
| 별도 프로필인데 북마크나 설정이 다시 나타남 | 각 프로필의 Chrome 로그인 계정과 저장 항목 확인 |
| 다른 기기에 업무 자료가 안 나타남 | 같은 업무 계정인지, 필요한 정보가 계정에 저장되는지 확인 |

이미 정보가 섞였다면 비밀번호나 북마크를 한꺼번에 지우면서 시험하지 않는 것이 좋습니다. 계정에 저장된 정보의 변경은 다른 기기에도 영향을 줄 수 있습니다. 어느 계정에 무엇이 저장되어 있는지 정리한 뒤 필요한 자료의 보존 방법을 먼저 확인하세요.

## 공용 PC와 프로필 삭제의 주의점

프로필은 작업 환경을 나누는 기능이지, 같은 컴퓨터를 쓰는 다른 사람에게 자료를 숨기는 잠금장치는 아닙니다. Google도 기기를 사용할 수 있는 사람이 다른 Chrome 프로필로 전환해 방문 사이트 등의 정보를 볼 수 있다고 안내합니다. 다른 사람과 접근 권한 자체를 나눠야 한다면 운영체제 사용자 계정과 기기 보안부터 따로 관리해야 합니다.

잠깐 빌린 PC라면 새 개인 프로필을 남기는 대신 **게스트 모드**가 용도에 더 맞습니다. 상단 `프로필` 메뉴에서 게스트 프로필을 열 수 있습니다. 공식 안내상 게스트에서는 다른 Chrome 프로필 정보를 보거나 변경할 수 없고, 종료하면 방문 기록·쿠키·사이트 데이터가 삭제됩니다.

<Image src="/chrome-work-personal-profiles/03-guest-mode.png" alt="게스트 모드의 용도와 다른 Chrome 프로필 정보 접근 제한을 설명하는 공식 도움말" caption="계속 사용할 내 작업 공간과 잠깐 빌린 기기의 이용은 구분하는 편이 좋습니다. Google Chrome 도움말, 2026년 10월 15일 확인." />

출처: [게스트로 Chrome 탐색](https://support.google.com/chrome/answer/6130773?hl=ko)

다만 게스트도 신뢰할 수 없는 PC를 안전하게 만들어 주지는 않습니다. 방문 사이트나 고용주·학교의 네트워크 등에 활동이 보일 수 있으며, Google은 민감한 웹사이트에는 신뢰할 수 있는 기기에서만 로그인하라고 안내합니다.

필요 없어진 프로필을 삭제할 때는 더 주의해야 합니다. `프로필 → 기타 Chrome 프로필 → Chrome 프로필 관리`에서 대상 프로필의 `더보기 → 삭제`를 선택하면 **그 프로필의 북마크·방문 기록·비밀번호·기타 설정이 컴퓨터에서 지워집니다.** 창 닫기나 Chrome 로그아웃과 같은 작업이 아닙니다. 다른 기기나 계정에 필요한 자료가 남아 있는지 확인하기 전에는 삭제하지 마세요.
