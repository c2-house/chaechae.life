### 목차

## 들어가며

중고차 시세를 조사할 때는 가격만큼이나 그 가격이 어떤 차량과 기준일의 정보인지 함께 남기는 게 중요합니다. 저는 Grok Bot에 제 중고차 시세를 조사한 뒤 Supabase에 저장해 달라고 요청한 적이 있습니다. 조사 결과를 따로 옮겨 적지 않고 조사와 저장을 하나의 작업으로 요청하는 방식입니다.

이번 글에서는 그 경험을 바탕으로 Grok Bot의 앱 연결과 조사 결과를 다루는 방법을 정리합니다. 원래 사용한 프롬프트는 공개하지 않고, 아래에는 별도의 한국어 예시를 준비했습니다. 화면은 이미 연결된 앱의 상태이며, 이 글을 위해 새 인증이나 데이터베이스 쓰기를 실행하지 않았습니다.

## Grok Bot과 일반 Grok의 차이

[Grok Bot 공식 FAQ](https://docs.x.ai/grok-bot/faq)에 따르면 Grok Bot은 일반 Grok 채팅 앱과 별도 앱입니다. Bot은 지속되는 클라우드 컴퓨터에서 브라우저, 파일과 연결된 앱을 사용해 작업하고, 앱을 닫은 뒤에도 작업을 계속할 수 있습니다. 질문에 답을 받는 것에 더해 여러 단계를 맡길 수 있지만 결과의 정확성이나 외부 서비스 사용 권한까지 자동으로 보장되는 것은 아닙니다.

여기서 **앱 연결**은 외부 서비스의 기능을 Bot에 제공하는 것이고, **스킬**은 작업 절차를 재사용할 수 있도록 정리한 지침입니다. **루틴**은 일정이나 특정 이벤트에 따라 작업을 실행하는 설정입니다. 반복 실행부터 만들기보다는 한 번의 작업과 결과를 먼저 확인하는 편이 안전합니다. 자세한 구분은 [스킬과 루틴 공식 문서](https://docs.x.ai/grok-bot/skills-routines-and-automations)를 참고하세요.

## Supabase 앱 연결과 확인

Supabase는 데이터베이스 등의 기능을 제공하는 서비스입니다. Grok Bot의 [앱 연결 안내](https://docs.x.ai/grok-bot/computer-and-apps)에 따르면 사이드바의 **Connect apps**에서 앱을 찾아 추가하고, 인증을 요청하면 제공자의 로그인과 권한 승인 절차를 완료합니다. 모바일에서는 프로필 메뉴의 Connect apps로 들어갑니다. 추가됨과 인증됨은 다른 상태이므로, 설치 후에도 인증 필요 또는 연결 끊김이 표시되는지 확인해야 합니다.

이 화면에서는 `default` 계정의 연결됨 표시와 Supabase 커넥터, 두 개의 스킬을 볼 수 있습니다. 아래의 쓰기 도구와 자동 검토 표시도 확인할 수 있는데, 이는 작업 내용을 무조건 안전하게 처리한다는 보증이 아닙니다. 연결할 때는 승인 화면의 범위를 읽고, 테스트용 프로젝트와 계정을 사용하는 것이 좋습니다. 채팅에 비밀번호나 API 키를 붙여 넣지 마세요.

공식 문서에서는 대화에 `@`를 입력해 연결된 앱을 작업에 붙일 수 있다고 안내합니다. 연결이 보이지 않으면 앱의 인증 상태를 확인하고 필요할 때 다시 연결하세요. Bot이 사용할 수 있는 범위는 연결한 계정과 서비스 권한의 영향을 받습니다.

### Cursor와 MCP 경로의 구분

[Supabase의 공식 소개](https://supabase.com/blog/ship-changes-to-your-supabase-backend-with-grok-bot)는 Grok Bot이 요청을 Cursor에 넘기고 Cursor가 Supabase MCP 서버를 통해 작업하는 별도의 흐름을 설명합니다. 위에 보이는 것은 Grok Bot의 Supabase 앱 연결 화면입니다. 두 경로를 같은 설정으로 취급하거나, 화면만 보고 Cursor 위임과 MCP 서버 구성이 완료됐다고 판단하면 안 됩니다.

## 조사와 저장 요청 나누기

시세 조사 결과를 데이터로 남길 때는 차량 조건과 출처를 같이 확인해야 합니다. 같은 차종이라도 연식, 주행거리, 사고 이력, 옵션과 매물 상태에 따라 가격 차이가 나기 때문입니다. 광고 가격과 실제 거래 가격도 구분해야 합니다. 제 요청은 중고차 시세를 조사한 뒤 Supabase에 저장해 달라는 것이었고, 공개할 원문 대신 아래처럼 별도 예시를 만들었습니다.

```text
테스트용 중고차 시세 조사 초안을 만들어 주세요.
대상 차종, 연식, 주행거리 범위와 조사 기준일은 먼저 저에게 확인해 주세요.
공개된 출처를 조사하고 매물별 가격, 연식, 주행거리, 출처 URL,
확인일을 표로 정리해 주세요. 확인할 수 없는 값은 추측하지 말고 비워 두세요.

저장할 프로젝트와 테이블 후보, 추가할 행의 미리보기를 보여 주세요.
기존 데이터와 중복될 가능성도 표시해 주세요.
제가 내용을 확인하고 명시적으로 승인하기 전에는 Supabase에 쓰거나
테이블을 만들거나 수정하지 마세요.
```

이것은 실제 입력이나 실행 결과가 아닌 **설명용 예시**입니다. 먼저 조사 범위를 정하고 출처와 미리보기를 확인한 뒤, 별도의 승인 여부를 결정하는 구조입니다. Bot이 가져온 링크는 직접 열어 차량 조건과 가격이 맞는지 살펴보세요. 접근이 막힌 사이트나 확인하지 못한 항목은 추정값으로 채우지 않도록 요청하는 편이 좋습니다.

저장을 승인하기로 했다면 대상 프로젝트와 테이블, 추가·변경될 행을 다시 확인하세요. 저장 후에는 Supabase에서 실제 레코드와 출처, 기준일, 중복 여부를 직접 확인해야 합니다. 화면의 연결됨 표시는 연결 상태를 보여줄 뿐, 어떤 조사 결과가 저장됐다는 증거는 아닙니다.

## 반복 실행과 권한

반복 조사가 필요하다면 일회성 작업의 출처와 결과가 만족스러운지 확인한 다음 루틴을 검토할 수 있습니다. 일정과 시간대, 실패 시 알림, 중복 처리, 승인 없이 허용할 작업을 구체적으로 정하세요. 시세 출처의 이용 조건이나 접근 제한도 확인해야 합니다. 사이트의 CAPTCHA나 로그인을 우회하도록 요청해서는 안 됩니다.

클라우드 컴퓨터의 파일과 브라우저 로그인은 같은 계정의 Bot들이 공유할 수 있습니다. Bot을 여러 개 만든다고 계정이나 파일이 서로 격리되는 것은 아닙니다. 운영 데이터에 쓰기 권한을 주기 전에 별도 테스트 환경, 백업과 권한 범위를 검토하고, 중요한 변경은 사람이 확인하는 절차를 두는 것이 좋습니다.

## 플랜과 사용량

2026년 11월 23일 확인한 [공식 FAQ](https://docs.x.ai/grok-bot/faq) 기준으로 신규 고객의 The X Subscription에서는 Premium, Super, Ultra에 Grok Bot이 포함되며 Free와 Plus에는 포함되지 않습니다. 기존 Cursor 플랜이나 일부 Grok 구독 연결은 별도 조건이 적용됩니다. 플랜별 주간 사용량과 초과 사용 설정에 따라 추가 비용이 생길 수 있으므로 계정의 사용량·결제 화면을 확인하세요. The X Subscription에서는 Grok Bot, Cursor와 Grok 앱이 주간 사용량을 공유하지만, 기존 Cursor 플랜에서는 Grok Bot과 Grok 앱의 사용량 계측이 별도입니다. 체험 제공 여부와 앱스토어 체험의 자동 결제 조건도 계정과 구매 경로에 따라 다릅니다.

Grok Bot은 조사와 정리, 저장 요청을 연결하는 데 유용한 선택지입니다. 다만 연결 자체보다 중요한 것은 **어떤 출처를 믿고 어떤 데이터를 어디에 쓸지**입니다. 처음에는 읽기와 미리보기로 시작하고, 결과를 확인한 뒤 쓰기나 반복 실행의 범위를 넓혀보세요.
