### 목차

## 들어가며

크롬에서 시크릿 창을 닫았는데 다운로드한 파일이 그대로 있거나, 시크릿 탭을 새로 열었는데 방금 로그인한 계정이 다시 보이면 의아할 수 있습니다. 이름은 시크릿인데 무엇을 숨겨 주는 걸까요?

**Chrome은 시크릿 세션의 방문 기록을 보관하지 않으며, 모든 시크릿 창을 닫으면 세션 쿠키를 지웁니다.** 다운로드한 파일과 북마크는 기기에 남습니다. 웹사이트가 자체적으로 보관하는 기록도 시크릿 창을 닫는 것과 별개입니다.

2026년 10월 28일 Google 공식 도움말을 확인하고, Windows의 Chrome 155.0.8059.79에서 시험용 쿠키와 사이트 저장소가 세션 종료 전후에 어떻게 달라지는지 비교했습니다.

## 기록이 남는 위치

[Google의 시크릿 모드 안내](https://support.google.com/chrome/answer/95464?hl=ko)를 기준으로 정리하면 다음과 같습니다.

| 정보 | 시크릿 모드의 처리 범위 |
| --- | --- |
| 시크릿 세션에서 방문한 사이트 기록 | 세션이 끝난 뒤 Chrome이 보관하지 않음 |
| 쿠키·사이트 데이터 | 세션 중 일시적으로 사용하고 종료 시 삭제 |
| 다운로드한 파일 | 직접 삭제할 때까지 기기에 남음 |
| 추가한 북마크·읽기 목록 항목 | 일반 탐색에서도 사용 가능 |
| 사이트에 직접 보낸 검색·주문·게시물 등 | 시크릿 창을 닫는 것만으로 사이트 쪽 데이터가 삭제되지 않음 |
| 학교·회사·인터넷 제공업체가 관찰할 수 있는 활동 | 시크릿 모드로 관찰을 차단하는 것은 아님 |

시크릿 창에서 쇼핑몰에 로그인해 주문하면 세션이 끝나도 구매 내역은 쇼핑몰 계정에 남습니다.

일반 창에서 이미 쌓인 방문 기록은 Chrome의 인터넷 사용 기록에서 따로 지우세요.

## 시크릿 탭과 세션의 차이

### 세션 중에 유지되는 정보

Chrome은 시크릿 세션 동안 로그인에 쓰이는 쿠키를 임시로 보관합니다. **새 시크릿 탭이나 창도 기존 시크릿 세션의 쿠키를 공유**하므로 같은 계정이 보일 수 있습니다. 모든 시크릿 창을 닫은 뒤 다시 열면 새 세션이 시작됩니다.

새 시크릿 세션은 일반 창의 로그인 상태를 가져오지 않습니다. 시크릿 창에서 직접 로그인하면 그 사이트는 로그인한 계정을 식별할 수 있습니다.

### 탭 유지와 세션 종료 비교

별도 Chrome 프로필에서 로컬 시험 페이지에 쿠키와 `localStorage` 값을 저장한 뒤, 같은 세션의 두 번째 탭과 세션 종료 뒤 새 창을 비교했습니다. `localStorage`는 웹사이트가 브라우저에 값을 보관하는 저장소입니다.

| 확인 시점 | 가상 쿠키 | localStorage 값 |
| --- | --- | --- |
| 시험 페이지에서 값을 저장한 직후 | 있음 | 있음 |
| 같은 세션의 두 번째 탭 | 있음 | 있음 |
| 첫 번째 탭만 닫고 두 번째 탭을 유지한 상태 | 있음 | 있음 |
| 시험 브라우저를 완전히 종료한 뒤 새 시크릿 세션으로 접속 | 없음 | 없음 |

반면 시험 서버가 따로 보관한 요청 경로 목록에는 이전 접속 경로가 남아 있었습니다. 브라우저의 임시 저장소가 비워지는 것과 서버가 받은 요청의 기록은 별개라는 것을 보여줍니다.

## 사이트와 회사의 기록 범위

Google에 따르면 웹사이트는 로그인하지 않은 방문자의 정보도 수집할 수 있습니다. 회사나 학교에서 볼 수 있는 범위는 기기 관리와 네트워크 구성에 따라 달라집니다.

[HTTPS](https://developer.mozilla.org/en-US/docs/Glossary/HTTPS)는 브라우저와 서버 사이의 통신을 TLS로 암호화합니다. 업무 기기에서 실제로 수집하는 정보는 조직의 개인정보·기기 관리 안내를 확인하세요.

## 목적에 맞는 모드 선택

| 하고 싶은 일 | 먼저 고려할 방법 |
| --- | --- |
| 내 PC에서 선물 검색 기록이 일반 방문 기록에 쌓이지 않게 하기 | 시크릿 모드, 사용 후 모든 시크릿 창 닫기 |
| 내 사이트가 로그인하지 않은 방문자에게 어떻게 보이는지 확인하기 | 새 시크릿 세션에서 로그인 없이 확인 |
| 업무·개인 계정과 북마크를 계속 나누어 쓰기 | 별도 Chrome 프로필 |
| 신뢰할 수 있는 다른 사람의 PC를 잠깐 빌려 쓰기 | 게스트 모드 |
| 사이트에 이미 저장한 주문·게시물·계정 데이터를 없애기 | 해당 서비스의 삭제·개인정보 관리 기능 |

업무·개인 환경을 계속 나누려는 경우에는 [크롬 프로필 분리 방법](/blog/chrome-work-personal-profiles)이 더 적합합니다. 시크릿은 세션이 끝나면 사이트 데이터를 지우므로, 로그인과 작업 환경을 계속 유지하려는 목적과는 맞지 않을 수 있습니다.

[게스트 모드](https://support.google.com/chrome/answer/6130773?hl=ko)에서는 다른 Chrome 프로필의 정보에 접근할 수 없습니다. 내 프로필에서 시크릿 창을 열면 기존 북마크와 설정을 사용할 수 있습니다. 민감한 사이트에는 신뢰할 수 있는 기기에서 로그인하세요.

## 사용 후 종료 확인

데스크톱에서는 **더보기 → 새 시크릿 창**으로 시작합니다. Windows에서는 `Ctrl + Shift + N`, Mac에서는 `⌘ + Shift + N`입니다. 주소 표시줄 오른쪽에서 시크릿 아이콘을 확인할 수 있습니다.

작업을 마칠 때는 다음 순서로 확인하면 됩니다.

1. 로그아웃해야 하는 사이트에서 로그아웃합니다.
2. **열려 있는 시크릿 창을 모두 닫습니다.**
3. 다운로드 파일이나 북마크가 필요 없다면 따로 지웁니다.

다시 열었을 때 이전 로그인 상태가 보이면 다른 시크릿 창이 남아 있었는지 확인하세요. 모두 닫았다면 해당 사이트의 로그인·재인증 방식을 확인하세요.

**시크릿 모드는 서드 파티 쿠키를 기본 차단**합니다. 외부 로그인 서비스가 작동하지 않으면 Google 도움말에 따라 필요한 사이트에서만 일시적으로 허용할 수 있습니다.
