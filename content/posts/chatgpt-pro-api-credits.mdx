### 목차

## Pro 구독에 추가된 API 혜택

자격을 충족하는 ChatGPT Pro 구독자는 **API 조직에 결제 주기당 100·200·500달러의 크레딧**을 신청할 수 있습니다. 첫 지급액은 남은 결제 기간에 비례하고, 받은 크레딧은 해당 주기가 끝나면 만료됩니다.

이 혜택은 [OpenAI API 변경 기록](https://developers.openai.com/api/docs/changelog)의 2026년 10월 28일 항목에 올라왔습니다. 지급 조건과 신청 절차는 한국 시간 10월 29일 확인한 공식 문서를 기준으로 정리했습니다.

## 지급 대상과 플랜별 금액

[공식 API 크레딧 가이드](https://developers.openai.com/api/docs/guides/chatgpt-api-credits)의 Pro 지급 기준은 다음과 같습니다. 금액은 미국 달러 기준의 **API 이용 잔액**이지 현금 환급이나 ChatGPT 구독료 할인액이 아닙니다.

| 공식 문서의 Pro 등급 | 한 월간 결제 주기 전체의 API 크레딧 |
| --- | --- |
| Pro 100달러 등급 | 100달러 |
| Pro 200달러 등급 | 200달러 |
| Pro 500달러 등급 | 500달러 |

내 구독의 달러 등급을 표와 대조하세요. 국내 최종 청구액은 결제 통화와 세금에 따라 달라질 수 있습니다.

<Image src="/chatgpt-pro-api-credits/00.png" alt="OpenAI 개발자 문서에 표시된 ChatGPT 구독자 API 크레딧 개요와 Pro 등급별 지급액" caption="OpenAI 개발자 문서의 Pro 등급별 지급액과 만료 조건. 2026년 10월 29일 확인." />

대상 유료 구독은 **7일 이상 활성 상태**여야 합니다. Plus와 무료 체험·무상 제공 구독은 제외되며, 혜택이 표시되는 시점은 국가와 계정 그룹에 따라 달라질 수 있습니다.

Business에도 별도 혜택이 있습니다. 유료 Standard 좌석당 20달러, Premium 좌석당 100달러를 합산하되 월간 결제 주기에는 워크스페이스 전체 500달러가 상한입니다. 개인마다 Pro처럼 지급하는 구조가 아니므로, Business 사용자는 소유자가 워크스페이스 조건을 따로 확인해야 합니다.

## 신청 준비와 공식 경로

### 계정과 API 조직 조건

API 조직은 API 사용량·결제·프로젝트를 관리하는 단위입니다. 신청 전에는 다음 조건을 확인하세요.

- ChatGPT 구독 계정과 연결에 사용하는 API 계정의 **이메일 주소가 같아야** 합니다.
- Pro 구독의 소유자이면서 크레딧을 받을 **API 조직의 소유자**여야 합니다.
- API 조직의 결제를 관리할 권한이 필요합니다. 결제 전용 역할만 있고 조직 소유자가 아니라면 충분하지 않습니다.
- 구독 하나는 API 조직 하나에 연결할 수 있고, API 조직에도 이런 활성 연결은 하나만 둘 수 있습니다.

조직이 여러 개라면 앱을 운영할 조직을 선택하세요. 크레딧은 선택한 조직의 사용량에 적용됩니다. 이미 연결한 조직을 바꾸려면 지원팀에 문의해 기존 크레딧이 어떻게 처리되는지 확인하세요.

API를 처음 쓰는 경우에는 같은 이메일의 Personal API Organization에 연결할 수 있습니다. 도움말에 따르면 ChatGPT에서 신청하기 전에 API 온보딩을 모두 마칠 필요는 없습니다.

### ChatGPT에서 신청

공식 문서가 안내하는 Pro 신청 순서는 다음과 같습니다.

1. Pro 구독을 소유한 계정으로 ChatGPT에 로그인합니다.
2. **Settings → Billing**으로 이동합니다. 한국어 화면에서는 설정의 결제 항목을 확인합니다.
3. API credits 혜택을 찾아 신청 흐름을 시작합니다.
4. 크레딧을 받을 API 조직과 화면에 표시된 지급액을 확인합니다.
5. 선택한 조직이 맞으면 혜택 활성화를 확정합니다.
6. [API Platform의 Billing](https://platform.openai.com/settings/organization/billing/overview)에서 연결한 조직을 선택하고, 실제 크레딧 지급을 확인합니다.

### API Platform에서 신청과 완료 확인

API Platform에서도 같은 혜택을 신청할 수 있습니다. 같은 이메일로 로그인해 소유한 조직을 선택한 뒤, **Billing → API credits 혜택**에서 연결할 Pro 구독을 확정하세요.

연결 뒤에는 해당 조직의 **Billing → Credit grants**에서 지급 내역과 금액, 만료일을 확인하세요.

## 첫 지급액과 만료 기준

### 남은 기간에 따른 첫 지급

Pro 200달러 등급인데 첫 지급액이 200달러보다 작다면 결제 갱신일을 확인하세요. 첫 지급액은 **현재 결제 주기에 남은 기간에 비례**합니다. 갱신일에 가까울수록 받는 금액과 사용 기간이 줄어듭니다.

한 번 활성화한 이후에는 대상 구독이 갱신될 때 자동으로 다시 지급됩니다. 매번 신청할 필요는 없지만 **혜택이 계속 제공되고 구독이 자격을 유지할 때**라는 조건이 붙습니다. OpenAI는 이 혜택이 추후 변경되거나 종료될 수 있다고 명시합니다.

### 주기 말 소멸과 구독 변경

월간 크레딧은 구독 결제 주기가 끝날 때 만료되며 **남은 금액은 다음 주기로 이월되지 않습니다.** 달력의 매월 말일이 아니라 본인의 결제 주기라는 점이 중요합니다.

구독 취소를 예약하는 것만으로 이미 지급된 크레딧이 즉시 회수되지는 않습니다. 현재 주기 만료까지 사용할 수 있지만 구독이 종료되거나 자격을 잃으면 이후 지급이 중단됩니다. Plus·Go·Free처럼 대상이 아닌 플랜으로 내리는 경우에는 주기 말에 API 조직 연결도 해제됩니다. 다만 승인된 전액 환불은 해당 결제에 연결된 미사용 프로모션 크레딧을 제거하는 별도 경우입니다.

## 사용할 수 있는 작업과 Codex 예외

이번 혜택은 연결된 조직에 청구되는 API 사용 비용을 충당합니다. 공식 문서는 Responses API, Agents API, Decisions API, 실시간 음성 API, Images API와 웹 검색·파일 검색·Code Interpreter 같은 내장 도구의 사용 및 저장 비용 등을 포함한다고 설명합니다.

이를테면 개인 앱에서 문서를 읽고 요약하는 기능을 만들거나, 이미지 입력을 분석하거나, 음성 인터페이스를 시험하는 데 활용할 수 있습니다. 다만 실제 API 요청은 **크레딧을 받은 조직에 속한 프로젝트의 API 키**로 보내야 합니다. 다른 조직의 키로 호출한 비용까지 옮겨 주는 혜택은 아닙니다.

Playground 역시 무조건 무료인 체험 화면이 아닙니다. API 호출과 Playground 활동은 조직의 적용 가능한 API 잔액을 사용합니다. 사용량은 모델과 기능에 따라 달라지므로, 크레딧을 고정된 질문 횟수로 환산할 수는 없습니다.

특히 Codex는 두 가지를 구분해야 합니다.

- **ChatGPT로 로그인한 Codex의 사용 한도를 늘려 주지 않습니다.**
- **API 키로 사용하는 Codex 비용도 이 혜택의 지원 대상이 아닙니다.**

개발자 문서가 Agents API를 지원 목록에 넣었다고 해서 모든 Codex 이용 방식까지 포함되는 것은 아닙니다. 평소 쓰는 도구가 어떤 인증 방식과 API로 비용을 청구하는지 먼저 확인해야 합니다.

## 무료 잔액 소진과 유료 비용

### API 카드 등록과 자동 충전

활성화된 프로모션 크레딧을 사용하는 데 **API 결제수단을 새로 등록할 필요는 없습니다.** ChatGPT 구독 결제와 API 유료 잔액 구매는 별도입니다.

주의할 부분은 크레딧을 다 쓴 다음입니다. [공식 개발자 문서](https://developers.openai.com/api/docs/guides/chatgpt-api-credits#when-your-free-credits-run-out)는 무료 크레딧을 먼저 쓰고, 이후 상태를 다음처럼 나눕니다.

| 무료 크레딧 소진 뒤 상태 | API 동작 |
| --- | --- |
| 구매한 API 크레딧이 남아 있음 | 구매한 잔액을 사용하며 계속 실행 |
| 사용할 크레딧이 전혀 없음 | HTTP 429 오류로 요청 실패 |

잔액 소진에 해당하는 오류 코드는 `credit_balance_exhausted`입니다.

<Image src="/chatgpt-pro-api-credits/02-credit-depletion.png" alt="무료 API 크레딧 소진 후 유료 잔액 사용과 잔액 없음 오류를 나눠 설명한 OpenAI 공식 문서" caption="OpenAI 개발자 문서의 무료 잔액 소진 후 API 동작과 유료 자동 충전 안내. 2026년 10월 29일 확인." />

**Auto Recharge를 켜면 유료 API 크레딧을 자동 구매합니다.** 무료 혜택 신청과는 별도 설정입니다. 이미 사용 중이라면 충전 기준 잔액과 목표 잔액, 월간 구매 한도를 확인하세요.

### 별도 결제 원칙과 사용 제한

[OpenAI 결제 도움말](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform)에 따르면 ChatGPT와 API는 계속 별도로 결제됩니다. API 호출 비용은 **Usage**, 크레딧 지급액·잔액·만료일은 **Billing**에서 각각 확인하세요.

API 요청 속도와 모델별 한도는 그대로 적용됩니다. HTTP 429가 발생하면 오류 코드로 잔액 소진과 요청 제한을 구분하고, 선택한 조직과 프로젝트를 확인하세요.

## 혜택이 보이지 않을 때의 확인 순서

[공식 도움말의 문제 해결 안내](https://help.openai.com/en/articles/20001626-api-credits-benefit-for-eligible-chatgpt-subscriptions)를 기준으로, 막힌 위치에 따라 확인할 항목을 나누면 편합니다.

1. **혜택 항목 자체가 없음**: 대상 Pro 등급인지, 유료 구독이 7일 이상 활성 상태인지, 올바른 계정과 이메일인지 확인합니다. 국가와 활성화 대상 계정 그룹 조건도 있으므로 조건을 충족하는데 보이지 않으면 지원팀에 문의합니다.
2. **조직 연결 실패 또는 잘못된 조직 표시**: 양쪽 소유권, API 결제 관리 권한, 이메일 일치, 기존 연결 유무를 확인합니다.
3. **연결됐지만 크레딧이 없음**: 연결한 API 조직을 선택했는지와 Billing의 Credit grants를 확인합니다. 다른 조직의 잔액을 보고 있지 않은지부터 살펴보는 것이 좋습니다.
4. **금액이나 만료가 예상과 다름**: Pro 등급 전체 지급액과 실제 남은 결제 기간, 신청 화면의 금액, 발급된 크레딧의 만료일을 비교합니다.

문의가 필요하면 신청 시각, 오류 문구, 해당 구독과 조직 정보를 정리해 공식 지원 경로로 전달하세요. 조직 식별자 등은 공개 게시물에 올리지 말고, 비밀번호나 API 키를 보내서는 안 됩니다.
