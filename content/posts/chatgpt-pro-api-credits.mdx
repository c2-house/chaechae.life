### 목차

## Pro 구독에 추가된 API 혜택

ChatGPT Pro를 결제하고 있어도 앱에 OpenAI API를 연결하려면 비용을 따로 생각해야 했습니다. 이제는 조건에 맞는 Pro 구독자가 **자신의 API 조직에 무료 크레딧을 신청할 수 있는 혜택**이 생겼습니다. 다만 Pro를 쓰고 있다는 이유만으로 모든 계정에 이미 지급된 것은 아닙니다.

[OpenAI API 변경 기록](https://developers.openai.com/api/docs/changelog)에는 이 혜택이 **2026년 10월 28일 항목**으로 올라와 있습니다. 이 글은 한국 시간 10월 29일 공식 개발자 문서와 도움말을 확인한 내용입니다. 공식 기록에 표시된 날짜와 한국에서 확인한 날짜를 구분하며, 모든 한국 계정에서 같은 시각에 활성화됐다는 뜻은 아닙니다.

먼저 답부터 정리하면, Pro의 월간 등급에 따라 **한 결제 주기 전체 기준으로 100·200·500달러**의 API 크레딧을 받을 수 있습니다. 최초 신청은 남은 결제 기간에 비례하고, 받은 크레딧은 해당 주기가 끝나면 소멸합니다. 신청 경로는 공식 안내를 기준으로 설명하며, 개인 계정의 신청 완료나 API 호출까지 실행한 후기는 아닙니다.

## 지급 대상과 플랜별 금액

[공식 API 크레딧 가이드](https://developers.openai.com/api/docs/guides/chatgpt-api-credits)의 Pro 지급 기준은 다음과 같습니다. 금액은 미국 달러 기준의 **API 이용 잔액**이지 현금 환급이나 ChatGPT 구독료 할인액이 아닙니다.

| 공식 문서의 Pro 등급 | 한 월간 결제 주기 전체의 API 크레딧 |
| --- | --- |
| Pro 100달러 등급 | 100달러 |
| Pro 200달러 등급 | 200달러 |
| Pro 500달러 등급 | 500달러 |

여기서 ‘최대 500달러’는 모든 Pro 구독자가 받는 공통 금액이 아닙니다. 본인이 어느 등급을 이용하는지 확인해야 합니다. 위 표는 혜택 산정용 달러 등급이며, 국내 결제 화면의 통화·세금 등을 포함한 최종 청구액을 그대로 나타내는 가격표는 아닙니다.

대상 유료 구독은 **최소 7일 이상 활성 상태**여야 합니다. Plus는 대상이 아니며 무료 체험과 무상 제공 구독도 제외됩니다. 도움말은 표시 여부가 국가와 혜택이 활성화된 계정 그룹에도 달려 있다고 안내합니다. 따라서 가입한 지 7일이 지났다는 사실만으로 혜택 버튼이 반드시 보인다고 단정할 수는 없습니다.

Business에도 별도 혜택이 있습니다. 유료 Standard 좌석당 20달러, Premium 좌석당 100달러를 합산하되 월간 결제 주기에는 워크스페이스 전체 500달러가 상한입니다. 개인마다 Pro처럼 지급하는 구조가 아니므로, Business 사용자는 소유자가 워크스페이스 조건을 따로 확인해야 합니다.

## 신청 준비와 공식 경로

### 계정과 API 조직 조건

API 조직은 API 사용량·결제·프로젝트를 관리하는 단위입니다. ChatGPT의 개인 대화 공간과 같지 않습니다. 신청 전에는 다음 조건을 확인하세요.

- ChatGPT 구독 계정과 연결에 사용하는 API 계정의 **이메일 주소가 같아야** 합니다.
- Pro 구독의 소유자이면서 크레딧을 받을 **API 조직의 소유자**여야 합니다.
- API 조직의 결제를 관리할 권한이 필요합니다. 결제 전용 역할만 있고 조직 소유자가 아니라면 충분하지 않습니다.
- 구독 하나는 API 조직 하나에 연결할 수 있고, API 조직에도 이런 활성 연결은 하나만 둘 수 있습니다.

조직을 여러 개 사용한다면 실제 앱을 운영할 곳인지 먼저 확인하는 편이 좋습니다. 기존 개인 프로젝트와 회사 프로젝트의 조직을 혼동하면, 크레딧을 받아 놓고도 다른 조직의 사용량에는 적용되지 않을 수 있습니다. 공식 문서는 수신 조직을 바꾸려면 지원팀에 문의하라고 안내하며, 변경 요청이 크레딧 이전이나 추가 지급을 보장하지는 않습니다.

API를 처음 쓰는 경우에는 같은 이메일의 Personal API Organization에 연결할 수 있습니다. 도움말에 따르면 ChatGPT에서 신청하기 전에 API 온보딩을 모두 마칠 필요는 없습니다.

### ChatGPT에서 신청

공식 문서가 안내하는 Pro 신청 순서는 다음과 같습니다.

1. Pro 구독을 소유한 계정으로 ChatGPT에 로그인합니다.
2. **Settings → Billing**으로 이동합니다. 한국어 화면에서는 설정의 결제 항목을 확인합니다.
3. API credits 혜택을 찾아 신청 흐름을 시작합니다.
4. 크레딧을 받을 API 조직과 화면에 표시된 지급액을 확인합니다.
5. 선택한 조직이 맞으면 혜택 활성화를 확정합니다.
6. [API Platform의 Billing](https://platform.openai.com/settings/organization/billing/overview)에서 연결한 조직을 선택하고, 실제 크레딧 지급을 확인합니다.

<Image src="/chatgpt-pro-api-credits/01-claim-guide.png" alt="ChatGPT 설정의 Billing에서 API 크레딧을 신청하도록 안내하는 공식 개발자 문서" caption="공식 문서의 ChatGPT 신청 경로입니다. 실제 계정의 신청 화면이나 지급 완료 화면이 아니라 절차를 설명하는 원문 캡처입니다. 출처: OpenAI Developers, 2026년 10월 29일 확인." />

공개 상태에서 API Billing 주소를 열면 로그인이 필요했습니다. 따라서 위 메뉴와 단계는 공식 안내이며, 로그인 이후 계정별 버튼 문구나 실제 지급액은 본인 화면에서 확인해야 합니다.

### API Platform에서 신청과 완료 확인

반대로 API Platform에서 시작할 수도 있습니다. 같은 이메일로 로그인한 뒤, 자신이 소유한 조직을 선택하고 **Billing → API credits 혜택**에서 연결할 Pro 구독을 선택해 확정하는 경로입니다. 두 경로는 같은 혜택을 연결하는 것이므로, 양쪽에서 따로 두 번 받는 방식은 아닙니다.

완료 기준은 ‘연결됐다는 표시’만이 아닙니다. 연결한 API 조직의 Billing에서 **Credit grants에 지급 내역이 생겼는지, 금액과 만료일이 무엇인지**까지 확인하는 것이 좋습니다. 공식 도움말도 조직 연결과 크레딧 발급을 별개의 결과로 구분합니다.

## 첫 지급액과 만료 기준

### 남은 기간에 따른 첫 지급

Pro 200달러 등급인데 처음 표시된 크레딧이 200달러보다 작다면, 먼저 결제 갱신일을 확인하세요. 첫 지급액은 **현재 유료 결제 주기에 남은 시간에 비례**합니다. 신청한 날부터 새로운 한 달을 주는 구조가 아닙니다.

예를 들어 갱신일이 가까워진 시점에 처음 신청하면, 해당 주기 전체 금액보다 적게 받고 사용할 기간도 짧을 수 있습니다. 정확한 지급액은 임의로 반올림해 예상하기보다 신청 확정 전 화면의 금액과 지급 후 만료일을 기준으로 판단해야 합니다.

한 번 활성화한 이후에는 대상 구독이 갱신될 때 자동으로 다시 지급됩니다. 매번 신청할 필요는 없지만 **혜택이 계속 제공되고 구독이 자격을 유지할 때**라는 조건이 붙습니다. OpenAI는 이 혜택이 추후 변경되거나 종료될 수 있다고 명시합니다.

### 주기 말 소멸과 구독 변경

월간 크레딧은 구독 결제 주기가 끝날 때 만료되며 **남은 금액은 다음 주기로 이월되지 않습니다.** 달력의 매월 말일이 아니라 본인의 결제 주기라는 점이 중요합니다.

구독 취소를 예약하는 것만으로 이미 지급된 크레딧이 즉시 회수되지는 않습니다. 현재 주기 만료까지 사용할 수 있지만 구독이 종료되거나 자격을 잃으면 이후 지급이 중단됩니다. Plus·Go·Free처럼 대상이 아닌 플랜으로 내리는 경우에는 주기 말에 API 조직 연결도 해제됩니다. 다만 승인된 전액 환불은 해당 결제에 연결된 미사용 프로모션 크레딧을 제거하는 별도 경우입니다.

API를 쓸 계획 없이 크레딧 액수만 보고 Pro를 올리는 것은 권하지 않습니다. 현금으로 되돌려 받는 돈이 아니고, 쓰지 않으면 사라지며, 앞으로도 같은 조건으로 계속 지급된다는 보장이 없기 때문입니다.

## 사용할 수 있는 작업과 Codex 예외

이번 혜택은 연결된 조직에 청구되는 API 사용 비용을 충당합니다. 공식 문서는 Responses API, Agents API, Decisions API, 실시간 음성 API, Images API와 웹 검색·파일 검색·Code Interpreter 같은 내장 도구의 사용 및 저장 비용 등을 포함한다고 설명합니다.

이를테면 개인 앱에서 문서를 읽고 요약하는 기능을 만들거나, 이미지 입력을 분석하거나, 음성 인터페이스를 시험하는 데 활용할 수 있습니다. 다만 실제 API 요청은 **크레딧을 받은 조직에 속한 프로젝트의 API 키**로 보내야 합니다. 다른 조직의 키로 호출한 비용까지 옮겨 주는 혜택은 아닙니다.

Playground 역시 무조건 무료인 체험 화면이 아닙니다. API 호출과 Playground 활동은 조직의 적용 가능한 API 잔액을 사용합니다. 사용량은 모델과 기능에 따라 달라지므로, 크레딧을 고정된 질문 횟수로 환산할 수는 없습니다.

특히 Codex는 두 가지를 구분해야 합니다.

- **ChatGPT로 로그인한 Codex의 사용 한도를 늘려 주지 않습니다.**
- **API 키로 사용하는 Codex 비용도 이 혜택의 지원 대상이 아닙니다.**

개발자 문서가 Agents API를 지원 목록에 넣었다고 해서 모든 Codex 이용 방식까지 포함되는 것은 아닙니다. 평소 쓰는 도구가 어떤 인증 방식과 API로 비용을 청구하는지 먼저 확인해야 합니다.

## 무료 잔액 소진과 유료 비용

### API 카드 등록과 자동 충전

활성화된 프로모션 크레딧을 사용하는 데 **API 결제수단을 새로 등록할 필요는 없습니다.** ChatGPT 구독 결제와 API 유료 잔액 구매는 별도입니다.

주의할 부분은 크레딧을 다 쓴 다음입니다. [공식 개발자 문서](https://developers.openai.com/api/docs/guides/chatgpt-api-credits#when-your-free-credits-run-out)는 무료 크레딧을 먼저 쓰고, 이후 상태를 다음처럼 나눕니다.

| 무료 크레딧 소진 뒤 상태 | API 동작 |
| --- | --- |
| 구매한 API 크레딧이 남아 있음 | 구매한 잔액을 사용하며 계속 실행 |
| 사용할 크레딧이 전혀 없음 | HTTP 429 오류로 요청 실패 |

잔액 소진에 해당하는 오류 코드는 `credit_balance_exhausted`입니다. **무료분이 끝나면 반드시 앱도 멈춘다고 생각하면 안 됩니다.** 기존에 구매해 둔 API 잔액이 있다면 그대로 소비할 수 있습니다.

<Image src="/chatgpt-pro-api-credits/02-credit-depletion.png" alt="무료 API 크레딧 소진 후 유료 잔액 사용과 잔액 없음 오류를 나눠 설명한 OpenAI 공식 문서" caption="무료 크레딧 이후에도 유료 잔액이 있으면 호출은 계속됩니다. 아래 Auto Recharge는 무료 혜택 연장이 아니라 유료 크레딧 충전입니다. 출처: OpenAI Developers, 2026년 10월 29일 확인." />

Auto Recharge는 유료 API 크레딧을 자동 구매하는 기능입니다. 무료 혜택을 받기 위한 필수 단계가 아니므로 무심코 켜지 않는 편이 좋습니다. 이미 사용하고 있다면 충전이 시작되는 기준 잔액, 충전 목표 잔액, 월간 구매 한도를 확인하세요. ‘API 크레딧을 받았다’는 것과 ‘추가 지출이 차단됐다’는 것은 다른 상태입니다.

### 별도 결제 원칙과 사용 제한

‘ChatGPT와 API는 별도 결제’라는 기존 설명이 완전히 사라진 것은 아닙니다. [현재 결제 도움말](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform)도 두 시스템이 별개임을 명시하면서, 대상 구독에 연결된 API 조직에는 프로모션 크레딧을 제공할 수 있다고 설명합니다.

즉, **결제 시스템을 합친 것이 아니라 API 쪽에 쓸 수 있는 잔액을 추가하는 혜택**입니다. API Usage에 표시되는 사용 비용도 크레딧 적용 후 실제 현금 청구액과 반드시 같지는 않습니다. 사용량은 Usage에서, 지급액·잔액·만료는 Billing의 크레딧 내역에서 나눠 확인해야 합니다.

크레딧이 있다고 요청 속도나 모델별 한도가 없어지는 것도 아닙니다. 오류가 나면 조직·프로젝트 선택, 잔액과 만료, 요청 제한을 먼저 살펴보세요. HTTP 429라는 숫자만 보고 곧바로 유료 크레딧을 더 사는 방식은 적절하지 않습니다.

## 혜택이 보이지 않을 때의 확인 순서

[공식 도움말의 문제 해결 안내](https://help.openai.com/en/articles/20001626-api-credits-benefit-for-eligible-chatgpt-subscriptions)를 기준으로, 막힌 위치에 따라 확인할 항목을 나누면 편합니다.

1. **혜택 항목 자체가 없음**: 대상 Pro 등급인지, 유료 구독이 7일 이상 활성 상태인지, 올바른 계정과 이메일인지 확인합니다. 국가와 활성화 대상 계정 그룹 조건도 있으므로 조건을 충족하는데 보이지 않으면 지원팀에 문의합니다.
2. **조직 연결 실패 또는 잘못된 조직 표시**: 양쪽 소유권, API 결제 관리 권한, 이메일 일치, 기존 연결 유무를 확인합니다. 반복 신청으로 연결 제한을 우회하려고 하지 않습니다.
3. **연결됐지만 크레딧이 없음**: 연결한 API 조직을 선택했는지와 Billing의 Credit grants를 확인합니다. 다른 조직의 잔액을 보고 있지 않은지부터 살펴보는 것이 좋습니다.
4. **금액이나 만료가 예상과 다름**: Pro 등급 전체 지급액과 실제 남은 결제 기간, 신청 화면의 금액, 발급된 크레딧의 만료일을 비교합니다.

문의가 필요하면 신청 시각, 오류 문구, 해당 구독과 조직 정보를 정리해 공식 지원 경로로 전달하세요. 조직 식별자 등은 공개 게시물에 올리지 말고, 비밀번호나 API 키를 보내서는 안 됩니다.

이미 Pro를 쓰면서 API로 작은 앱이나 자동화를 만들어 보고 싶었다면 확인할 가치가 있는 혜택입니다. 시작점은 결제수단 등록이나 플랜 업그레이드가 아니라 **현재 구독의 혜택 표시, 받을 조직, 실제 지급액과 만료일 확인**입니다. 그다음 유료 잔액과 자동 충전 설정을 확인하면 무료로 시작한 실험이 어디서 비용 지출로 이어질 수 있는지도 구분할 수 있습니다.
