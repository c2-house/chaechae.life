### 목차

## 들어가며

**`설정 → 시스템 → 저장소`에서 C 드라이브의 가장 큰 범주부터 확인하세요.** `임시 파일`이 크면 삭제할 항목을 고르고, `설치된 앱`이 크면 사용하지 않는 대용량 앱부터 살펴봅니다. 문서·사진이 가장 크다면 다른 드라이브로 옮기거나 OneDrive의 `공간 확보`를 쓰는 편이 효과적입니다.

## 정리 전 C 드라이브 확인

1. 작업 표시줄의 폴더 모양 아이콘이나 `Windows 키 + E`로 파일 탐색기를 엽니다.
2. 왼쪽에서 `내 PC`를 선택하고 `장치 및 드라이브` 아래의 `로컬 디스크 (C:)`를 찾습니다.
3. 드라이브 아래에 표시된 **남은 용량 숫자**를 적어둡니다. 정리한 뒤 같은 위치에서 다시 비교할 기준입니다.

예를 들어 남은 용량이 `5GB`에서 `20GB`로 바뀌었다면 `15GB`를 확보한 셈입니다.

## 저장소 범주 확인

1. `시작`에서 `설정`을 열고 `시스템 → 저장소`로 이동합니다.
2. C 드라이브의 사용량과 `임시 파일`, `설치된 앱` 등 표시된 범주를 확인합니다. 나머지는 `더 많은 범주 표시`를 눌러 살펴봅니다.
3. 용량이 큰 범주를 선택해 세부 내용을 확인한 뒤 아래 방법 중 맞는 것을 고릅니다. 범주 이름과 크기는 무엇을 살펴볼지 알려주는 단서이지, 표시된 용량 전체를 지워도 된다는 뜻은 아닙니다.

개인 파일은 한 항목으로만 표시되지 않고 문서, 사진, 동영상 등으로 나뉠 수 있습니다. `기타`가 크다면 선택해 표시되는 위치를 확인하고, 내용과 용도를 아는 파일부터 살펴보세요.

## 임시 파일과 다운로드

`저장소 → 임시 파일`을 열면 Windows가 정리할 수 있는 항목과 각 항목의 설명을 보여줍니다. 목록을 읽고 **없어도 되는 항목만 선택**한 다음 `파일 제거`를 누릅니다. 선택 전에는 이미 체크된 항목도 확인하세요. `저장소 → 정리 권장 사항`에서도 임시 파일과 큰 파일 등의 후보를 살펴볼 수 있습니다.

### 다운로드 폴더

다운로드 폴더에는 설치 파일뿐 아니라 직접 받은 문서와 사진도 있을 수 있습니다. 목록에 다운로드가 나온다고 해서 임시 캐시와 똑같이 지우지 마세요. 파일 탐색기의 `다운로드` 폴더에서 이름과 내용을 보고, 필요한 파일은 남긴 뒤 불필요한 것만 선택해 삭제합니다. 휴지통에 들어간 파일도 공간을 차지하므로 비우기 전에 복원할 파일이 없는지 확인합니다.

### Windows.old와 이전 설치

Windows 업데이트나 업그레이드 후 `이전 Windows 설치`가 정리 대상으로 나타날 수 있습니다. 이 항목에는 이전 설치로 돌아가는 데 필요한 파일이 포함됩니다. **삭제하면 해당 파일을 이용해 이전 Windows 버전으로 돌아갈 수 없으므로**, 되돌릴 필요가 있는지 확인한 뒤 결정하세요. Windows.old 폴더를 직접 지우기보다 Windows가 제공하는 정리 항목을 이용하는 편이 안전합니다.

## 설치된 앱과 앱 캐시

저장소에서 `설치된 앱`을 열고 크기순 정렬이 제공되면 큰 앱부터 확인합니다. 사용하지 않는 앱을 찾았다면 해당 앱의 메뉴에서 `제거`를 선택하고 화면의 안내를 따릅니다. 게임이나 작업 프로그램은 저장 데이터와 재설치 방법을 먼저 확인하고, Windows 구성 요소나 용도를 모르는 앱은 그대로 두세요.

앱이 만드는 캐시는 나중에 다시 만들 수 있는 데이터인 경우가 있지만, 앱별로 보관하는 내용과 삭제 결과가 다릅니다. 앱의 설정에 캐시 정리 기능이 있다면 그 설명을 확인해 사용하세요. **캐시와 직접 작성한 문서·프로젝트 파일은 다릅니다.** 용량이 크다는 이유만으로 앱 데이터 폴더나 문서를 통째로 삭제하지 않는 편이 좋습니다.

## 개인 파일과 OneDrive

문서·사진·동영상 범주가 크다면 해당 위치를 열어 큰 파일 중 실제로 필요 없는 항목을 골라봅니다. 보관할 파일은 여유 공간이 있는 다른 드라이브나 외장 저장장치에 먼저 복사하고, 복사본이 열리는지 확인한 뒤 원본을 지울지 결정하세요. C 드라이브 안에서 다른 폴더로만 옮기면 C 드라이브의 공간은 늘어나지 않습니다.

### OneDrive 공간 확보와 삭제

OneDrive를 사용한다면 파일 탐색기에서 해당 OneDrive 폴더와 파일의 동기화 상태를 먼저 확인합니다. 동기화가 완료된 파일을 온라인에 남기면서 PC 공간만 확보하려면 파일을 마우스 오른쪽 버튼으로 눌러 `공간 확보`를 선택합니다. 파일은 온라인 전용으로 바뀌고, 다음에 열 때 인터넷 연결이 필요합니다. 파란 구름 표시는 온라인 전용, 초록색 체크는 PC에서 사용할 수 있는 파일을 뜻합니다.

반면 OneDrive 동기화 폴더의 파일을 `삭제`하면 **클라우드와 다른 동기화 장치에도 삭제가 반영될 수 있습니다.** 동기화 오류나 업로드 대기 상태라면 먼저 해결하고, 보관이 중요한 파일은 별도 사본도 확인하세요. 오프라인에서 꼭 필요한 파일은 `항상 이 장치에 유지`를 사용하고 공간 확보 대상에서 제외하는 편이 좋습니다.

바탕 화면 백업을 끄기 전에는 [OneDrive 바탕 화면 백업 중지와 파일 보관 방법](/blog/onedrive-desktop-backup-stop)에서 파일이 남는 위치를 확인하세요.

## 시스템 및 예약

`시스템 및 예약`에는 Windows 작동과 업데이트 등에 필요한 공간이 포함됩니다. 이 범주가 크다고 해서 `WinSxS`나 Windows 시스템 폴더 안의 파일을 파일 탐색기에서 직접 지우지 마세요. 먼저 `정리 권장 사항`이나 앞서 확인한 다른 범주에서 선택할 수 있는 항목을 살펴봅니다. 시스템 및 예약의 세부 항목이 계속 커서 원인을 알기 어렵다면, 내용을 기록하고 Microsoft 지원이나 회사 PC의 관리자에게 문의하는 것이 안전합니다.

## 정리 후 남은 용량 확인

다시 파일 탐색기의 `내 PC → 로컬 디스크 (C:)`에서 **남은 용량 숫자**를 확인하고 처음 적어둔 값과 비교합니다. 공간이 충분해졌다면 하려던 작업이나 업데이트를 다시 시도해 보세요. 변화가 작다면 저장소 화면으로 돌아가 다음으로 큰 범주를 확인합니다. 정리 직후 계산이나 표시 갱신에 시간이 걸릴 수도 있습니다.

공간이 다시 빠르게 줄어들거나 정리 후에도 업데이트에 필요한 공간을 확보하지 못한다면 무작정 더 지우지 말고, 어떤 범주가 커지는지 확인하세요. Microsoft의 드라이브 공간 확보 문서에는 임시 폴더가 빠르게 차는 경우와 업데이트 문제에 대한 추가 안내도 있습니다.

### 저장소 센스

앞으로 자동 정리를 사용하고 싶다면 `설정 → 시스템 → 저장소 → 저장소 센스`에서 실행 주기와 삭제 대상을 확인한 뒤 켤 수 있습니다. Microsoft 안내상 기본 설정에서는 휴지통의 오래된 항목이 삭제될 수 있습니다. 다운로드 폴더나 클라우드 콘텐츠도 별도 설정에 따라 영향을 받을 수 있으니, 켜기 전에 각 기간과 대상을 읽고 원하는 값으로 선택하세요.
