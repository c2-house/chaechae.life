### 목차

## 들어가며

ChatGPT에서 업무용 프로젝트를 만들었는데 개인 대화에서 했던 이야기가 답변에 섞일 수 있을까요? 반대로 프로젝트에 올린 자료가 일반 대화에도 영향을 줄까요? 이때 살펴볼 설정이 **기본 메모리**와 **프로젝트 전용 메모리**입니다.

OpenAI의 설명에 따르면 프로젝트 전용 메모리는 해당 프로젝트 안의 대화를 다른 프로젝트나 일반 대화와 구분해 참조하도록 합니다. 기본 메모리는 저장된 메모리를 사용할 수 있고, 프로젝트 밖 대화의 참조 범위는 플랜에 따라 다릅니다. 다만 두 설정 모두 계정과 워크스페이스의 메모리 조건을 따릅니다.

아래 내용은 2026년 11월 3일 [OpenAI 프로젝트 도움말](https://help.openai.com/en/articles/10169521-projects-in-chatgpt)을 확인해 정리했습니다. 실제 계정에서 설정을 바꾸거나 대화 간 정보 차단을 시험한 결과는 아닙니다. 메뉴와 기능 제공 여부는 계정과 관리 설정에 따라 다를 수 있습니다.

## 프로젝트 안팎의 참조 범위

프로젝트는 관련 대화, 파일, 프로젝트 지침을 한곳에 모으는 공간입니다. 같은 프로젝트에 대화가 여러 개 있으면 ChatGPT가 다른 대화의 내용을 맥락으로 활용할 수 있습니다. **참조할 수 있다는 것과 모든 대화를 빠짐없이 기억하거나 매번 같은 내용을 사용하는 것은 다릅니다.**

| 확인할 범위 | 프로젝트 전용 메모리 | 기본 메모리 |
| --- | --- | --- |
| 프로젝트 안의 다른 대화 | 참조할 수 있음 | 참조할 수 있음 |
| 기존에 저장된 개인 메모리 | 프로젝트 대화에서 참조하지 않음 | 계정 설정에 따라 참조 가능 |
| 프로젝트 밖 대화 | 프로젝트 안팎에서 서로 참조하지 않음 | 플랜과 설정에 따라 다름 |
| 공유 프로젝트 | 공유 시 전용 메모리로 설정 | 공유 프로젝트에서는 선택 불가 |

여기서 기본 메모리의 차이가 중요합니다. 공식 도움말은 **Enterprise와 Edu**에서는 기본 메모리 프로젝트의 대화도 프로젝트 밖 대화를 참조하거나 밖에서 참조되지 않는다고 설명합니다. 반면 **Business를 포함한 다른 플랜**에서는 프로젝트 대화와 일반 대화 등 프로젝트 밖 대화가 서로 참조될 수 있습니다. 다른 프로젝트가 전용 메모리라면 그 프로젝트에는 같은 방식으로 접근하지 않습니다. 실제 사용 가능 범위는 계정과 조직 설정도 함께 확인해야 합니다.

가령 개인 계정에서 ‘여행 계획’과 ‘업무 문서’ 프로젝트를 따로 쓴다고 가정해보겠습니다. 업무 프로젝트를 전용 메모리로 설정하면 기존 개인 메모리나 여행 프로젝트의 대화를 업무 프로젝트의 맥락으로 참조하지 않는 것이 공식적으로 설명된 동작입니다. 업무 프로젝트 안의 다른 대화와 파일은 여전히 해당 프로젝트의 맥락으로 사용될 수 있습니다. 이 예시는 설정의 의미를 설명하기 위한 가상 사례입니다.

## 설정 선택 기준

개인 취향처럼 이미 저장된 정보를 프로젝트에서도 활용하고 싶다면 기본 메모리가 편할 수 있습니다. 다만 개인 계정 등에서는 프로젝트 밖 대화도 참조 대상이 될 수 있으므로, 주제를 나누기 위해 폴더만 만든다고 참조 범위까지 분리된다고 생각하면 안 됩니다.

서로 다른 업무나 주제를 분리해 다루고 싶다면 전용 메모리를 고려할 수 있습니다. 프로젝트 안의 대화와 파일을 활용하되, 프로젝트 밖의 저장 메모리와 대화를 끌어오지 않도록 범위를 정하는 방식입니다. 평소 저장해 둔 문체나 선호도도 참조되지 않으므로 해당 프로젝트에 필요한 조건은 프로젝트 지침이나 자료에 직접 정리하는 편이 낫습니다.

단, **프로젝트 전용 메모리는 비밀 금고나 자료 삭제 기능이 아닙니다.** 공유 프로젝트에서는 구성원이 프로젝트의 대화와 파일을 볼 수 있고 파일을 다운로드할 수 있습니다. 공유하기 전에는 구성원과 접근 권한, 포함된 자료를 먼저 살펴봐야 합니다.

## 프로젝트 메모리 설정

공식 도움말 기준으로 새 프로젝트를 만들 때 메모리 방식을 선택할 수 있으며, 기존 프로젝트도 설정을 바꿀 수 있습니다. 오래된 안내에서 ‘처음 만들 때만 선택할 수 있다’고 봤더라도 현재 계정의 프로젝트 설정을 확인해보세요.

1. 설정을 확인할 프로젝트를 엽니다.
2. 프로젝트의 더보기 메뉴를 열고 **Project settings**를 선택합니다.
3. **Memory**에서 **Default memory** 또는 **Project-only memory**를 선택합니다.
4. **Save**를 누르고 프로젝트 설정을 다시 열어 선택한 항목을 확인합니다.

영문 메뉴 이름은 공식 도움말 기준입니다. 설정 변경은 반영까지 몇 시간이 걸릴 수 있습니다. 전용 메모리로 바꾸면 프로젝트 정보는 프로젝트 밖에서 쓰이는 메모리에서 제거되지만, 프로젝트의 대화와 파일은 그 안에 남아 맥락으로 사용될 수 있습니다. 즉 설정 전환 자체가 프로젝트 자료를 삭제하지는 않습니다.

공유된 프로젝트는 자동으로 전용 메모리를 사용하며 기본 메모리로 전환할 수 없습니다. 모든 프로젝트에 전용 메모리를 한꺼번에 적용하는 전역 설정은 없으므로 프로젝트마다 확인해야 합니다.

### 선택 항목이 보이지 않을 때

먼저 개인 설정의 메모리 사용 여부와 워크스페이스의 제한을 확인합니다. 공식 도움말에 따르면 **Enable memory**가 보이는 계정은 이를 켜야 합니다. 저장 메모리와 대화 기록 참조를 따로 제어하는 계정에서는 Enterprise 사용자는 개인 설정의 저장 메모리 참조와 워크스페이스 메모리가 필요하고, 그 외 구독은 저장 메모리 참조와 대화 기록 참조를 켜야 합니다.

회사나 학교의 관리형 계정에서는 조직이 메모리 기능을 허용해야 할 수도 있습니다. 메뉴가 없다고 개인 설정을 무작정 변경하기보다는 현재 계정 유형과 관리자 정책부터 확인하는 게 좋습니다. 메모리를 켜면 다른 대화의 개인화 범위에도 영향을 줄 수 있으니 표시된 설명을 읽고 선택하세요.

## 원하지 않는 맥락과 개인정보

프로젝트 메모리는 개인의 저장 메모리처럼 별도의 항목 목록이 표시되지 않습니다. 특정 프로젝트 대화를 더 이상 맥락으로 사용하지 않게 하려면 OpenAI는 해당 대화를 삭제하거나, 프로젝트의 메모리 설정이 허용할 때 다른 프로젝트로 이동하는 방법을 안내합니다. **삭제는 복구할 수 없는 작업**이므로 먼저 대상 대화와 보관이 필요한 내용을 확인해야 합니다.

프로젝트의 파일이나 지침에 같은 정보가 남아 있다면 그것도 별도로 살펴봐야 합니다. 특정 대화를 옮겼다는 사실만으로 프로젝트의 모든 자료에서 같은 내용이 사라진 것은 아닙니다. 일반 대화 삭제와 개인 메모리 삭제의 차이는 [ChatGPT 대화를 삭제해도 기억이 남는 이유](/blog/chatgpt-delete-memory)에서 따로 정리했습니다.

또 하나 구분할 것이 **모델 개선 설정**입니다. 프로젝트 전용 메모리는 대화 사이에서 어떤 맥락을 참조할지에 관한 설정이지, 데이터의 모델 학습 사용을 끄는 스위치가 아닙니다. OpenAI는 개인 Free·Plus·Pro 계정에서 ‘Improve the model for everyone’ 설정이 켜져 있으면 프로젝트에서 접근한 정보를 모델 개선에 사용할 수 있다고 설명합니다. Business·Enterprise·Edu 등 조직용 워크스페이스에는 별도 기본 정책과 관리 설정이 적용됩니다. 개인 계정에서 모델 개선을 껐더라도 답변에 좋아요나 싫어요 같은 피드백을 보내면 해당 대화 전체가 모델 학습에 사용될 수 있다는 별도 조건도 있습니다.

업무와 개인 대화가 섞이는 것이 걱정된다면 먼저 프로젝트의 메모리 방식을 확인하고, 공유 여부와 모델 개선 설정은 각각 따로 확인해보세요. 세 설정이 다루는 문제는 서로 다릅니다.
