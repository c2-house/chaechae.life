### 목차

## 들어가며

**프로젝트 전용 메모리**는 대화에서 참조하는 범위를 해당 프로젝트 안으로 제한합니다. **기본 메모리**는 저장된 메모리를 활용할 수 있으며, 프로젝트 밖 대화의 참조 범위는 플랜에 따라 다릅니다. 아래 설정 경로는 2026년 11월 3일 도움말을 기준으로 정리했습니다. [OpenAI 프로젝트 도움말](https://help.openai.com/en/articles/10169521-projects-in-chatgpt)

## 프로젝트 안팎의 참조 범위

프로젝트는 관련 대화, 파일, 지침을 모아두는 공간입니다. ChatGPT는 답변에 필요한 맥락을 같은 프로젝트 안의 다른 대화에서 가져올 수 있습니다.

| 확인할 범위 | 프로젝트 전용 메모리 | 기본 메모리 |
| --- | --- | --- |
| 프로젝트 안의 다른 대화 | 참조할 수 있음 | 참조할 수 있음 |
| 기존에 저장된 개인 메모리 | 프로젝트 대화에서 참조하지 않음 | 계정 설정에 따라 참조 가능 |
| 프로젝트 밖 대화 | 프로젝트 안팎에서 서로 참조하지 않음 | 플랜과 설정에 따라 다름 |
| 공유 프로젝트 | 공유 시 전용 메모리로 설정 | 공유 프로젝트에서는 선택 불가 |

**Enterprise와 Edu**에서는 기본 메모리도 대화의 참조 범위가 프로젝트 안으로 제한됩니다. **Business를 포함한 다른 플랜**에서는 기본 메모리 프로젝트의 대화와 일반 대화가 서로 참조될 수 있습니다. 전용 메모리 프로젝트의 대화는 해당 프로젝트 안에서만 참조합니다.

## 설정 선택 기준

이미 저장해 둔 문체나 취향을 새 프로젝트에서도 쓰고 싶다면 기본 메모리가 편합니다. 업무 문서에 개인 대화나 다른 프로젝트의 맥락이 섞이는 걸 막으려면 전용 메모리를 선택하세요. 전용 메모리에서 사용할 문체나 선호도는 프로젝트 지침에 적어두면 됩니다.

**공유 프로젝트의 구성원은 프로젝트 대화와 파일을 볼 수 있고 파일을 다운로드할 수 있습니다.** 공유 전에는 구성원과 접근 권한, 첨부한 자료를 확인하세요.

## 프로젝트 메모리 설정

새 프로젝트를 만들 때 메모리 방식을 고를 수 있습니다. 기존 프로젝트에서는 다음 경로에서 바꿀 수 있습니다.

1. 설정을 확인할 프로젝트를 엽니다.
2. 프로젝트의 더보기 메뉴를 열고 **Project settings**를 선택합니다.
3. **Memory**에서 **Default memory** 또는 **Project-only memory**를 선택합니다.
4. **Save**를 누르고 프로젝트 설정을 다시 열어 선택한 항목을 확인합니다.

변경 사항이 반영되기까지 몇 시간이 걸릴 수 있습니다. 전용 메모리로 바꾸면 프로젝트 정보는 프로젝트 밖에서 쓰이는 메모리에서 제거됩니다. 프로젝트 안의 대화와 파일은 그대로 남아 맥락으로 쓰일 수 있습니다.

공유된 프로젝트는 자동으로 전용 메모리를 사용하며 기본 메모리로 전환할 수 없습니다. 모든 프로젝트에 전용 메모리를 한꺼번에 적용하는 전역 설정은 없으므로 프로젝트마다 확인해야 합니다.

### 선택 항목이 보이지 않을 때

먼저 개인 설정의 메모리 사용 여부와 워크스페이스의 제한을 확인합니다. 공식 도움말에 따르면 **Enable memory**가 보이는 계정은 이를 켜야 합니다. 저장 메모리와 대화 기록 참조를 따로 제어하는 계정에서는 Enterprise 사용자는 개인 설정의 저장 메모리 참조와 워크스페이스 메모리가 필요하고, 그 외 구독은 저장 메모리 참조와 대화 기록 참조를 켜야 합니다.

회사나 학교 계정에서 메뉴가 보이지 않으면 관리자에게 메모리 사용이 허용되어 있는지 확인하세요. 개인 설정에서 메모리를 켜면 다른 대화의 개인화 범위도 달라질 수 있습니다.

## 원하지 않는 맥락과 개인정보

프로젝트 메모리는 개인의 저장 메모리처럼 별도의 항목 목록이 표시되지 않습니다. 특정 프로젝트 대화를 더 이상 맥락으로 사용하지 않게 하려면 OpenAI는 해당 대화를 삭제하거나, 프로젝트의 메모리 설정이 허용할 때 다른 프로젝트로 이동하는 방법을 안내합니다. **삭제는 복구할 수 없는 작업**이므로 먼저 대상 대화와 보관이 필요한 내용을 확인해야 합니다.

같은 정보가 첨부 파일이나 프로젝트 지침에도 들어 있다면 그 자료도 확인하세요. [ChatGPT 대화를 삭제해도 기억이 남는 이유](/blog/chatgpt-delete-memory)

**데이터의 학습 사용 여부는 모델 개선 설정에서 관리합니다.** 개인 Free·Plus·Pro 계정에서 ‘Improve the model for everyone’이 켜져 있으면 OpenAI가 프로젝트에서 접근한 정보를 모델 개선에 사용할 수 있습니다. Business·Enterprise·Edu 워크스페이스에는 별도 정책과 관리 설정이 적용됩니다. 개인 계정에서 모델 개선을 껐더라도 답변에 좋아요나 싫어요를 보내면 해당 대화 전체가 학습에 사용될 수 있습니다.
