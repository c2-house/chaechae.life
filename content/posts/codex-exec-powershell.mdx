### 목차

발행할 MDX 원고 한 편을 지정하면 **깨진 썸네일과 내부 링크를 찾고, 실제 파일에 맞춰 경로를 고칠 수 있습니다.** 채채 테크에 올라온 글을 로컬에 복제해 썸네일과 링크에 오타를 넣고, 아래 명령으로 두 경로를 복구했습니다.

## 원고 한 편을 검사하고 고치기

<a href="/downloads/codex-exec-powershell/check-post.mjs" download="check-post.mjs">check-post.mjs 다운로드</a>에서 받은 파일을 `package.json`이 있는 저장소 루트에 넣으세요. 이 도구는 [채채 테크 저장소](https://github.com/c2-house/chaechae.life)의 MDX와 이미지 경로 규칙에 맞춰 만들었습니다. Node.js 22 환경에서 저장소 의존성을 `npm ci`로 설치하고, Codex CLI에 로그인한 뒤 PowerShell에서 실행하면 됩니다.

```powershell
node ./check-post.mjs content/posts/chatgpt-project-memory.mdx --fix
```

**`content/posts/chatgpt-project-memory.mdx`를 발행할 원고 경로로 바꾸세요.** 오류 목록만 보고 싶다면 `--fix`를 빼면 됩니다. 원고에 깨진 경로가 있으면 `MISSING`을 출력하고 종료 코드 `1`을 반환합니다.

## 썸네일과 링크 오타는 어떻게 잡혔을까?

실습에 쓴 글은 `ChatGPT 프로젝트 전용 메모리와 기본 메모리의 차이`입니다. 원고의 `thumbnail` 경로에서 `00.png`를 `000.png`로 바꾸고, 본문 링크 주소에는 `memory` 대신 `memroy`를 넣었습니다. 실제 사이트 미리보기에서 대표 이미지가 비었고, 본문 링크를 열면 404가 반환됐습니다.

<Image src="/codex-exec-powershell/mdx-repair-01-before.png" alt="테크 블로그 로컬 미리보기에서 대표 이미지가 비어 있는 ChatGPT 프로젝트 메모리 글" caption="썸네일 경로에 숫자 하나를 더하자 제목 아래 대표 이미지가 비었습니다." />

검사기는 글 상단의 `thumbnail`, 본문에 `<Image src="…">`로 적은 이미지 경로, 마크다운 형식의 `/blog/` 링크를 실제 파일 이름과 대조합니다. 이 사이트에서는 `/chatgpt-project-memory/00.png`가 `public/images/blog/chatgpt-project-memory/00.png`를 가리키고, `/blog/chatgpt-delete-memory`는 `content/posts/chatgpt-delete-memory.mdx`에 대응합니다.

## Codex에 맡길 부분과 직접 볼 부분

**깨진 경로는 스크립트가 찾고, 대체 후보는 `codex exec`가 고릅니다.** `--fix`를 실행하면 Codex는 누락된 경로, 링크 문구, 후보 파일명과 글 제목을 받아 수정안을 반환합니다. 스크립트는 그중 실제로 존재하는 경로만 원고에 반영한 뒤 같은 검사를 다시 돌립니다. [OpenAI 비대화형 실행 안내](https://learn.chatgpt.com/docs/non-interactive-mode)

```text
MISSING [thumbnail] /chatgpt-project-memory/000.png
MISSING [post] /blog/chatgpt-delete-memroy
FIX /chatgpt-project-memory/000.png → /chatgpt-project-memory/00.png
FIX /blog/chatgpt-delete-memroy → /blog/chatgpt-delete-memory
PASS 같은 검사에서 누락 경로가 0개입니다.
```

`PASS`를 받으면 `git diff -- content/posts/chatgpt-project-memory.mdx`로 경로 변경을 확인하세요. `REVIEW`가 남았다면 출력된 경로를 직접 확인해 수정한 뒤 다시 검사하세요. 같은 주제의 글이나 비슷한 사진이 여럿 있을 때는 파일 이름이 맞아도 의도한 대상인지 확인하는 게 좋습니다.

## 발행 전 미리보기에서 확인하기

평소 쓰는 블로그 미리보기에서 해당 원고를 열고, 대표 이미지가 뜨는지 확인한 뒤 수정한 링크를 직접 눌러보세요. 이번 실습에서는 제목 아래 이미지가 다시 보였고, 링크는 `ChatGPT 대화를 삭제해도 기억이 남는 이유` 글로 연결됐습니다.
