### 목차

지난주에 받은 기차표를 찾는데 다운로드 폴더에 `document.pdf`, `download (1).pdf`만 보이면 결국 하나씩 열어보게 됩니다. 이번에는 PDF 안의 날짜와 제목을 읽어 **`download (1).pdf`를 `교통/2026-11-04_서울_부산_열차표.pdf`로 정리**해 봤습니다. 영수증과 설명서도 한 번에 이름을 붙이고, 다음에 새 PDF를 받으면 같은 명령을 다시 쓰면 됩니다.

## 1. 실습 파일 받아서 준비하기

<a href="/downloads/codex-exec-powershell/pdf-organizer.zip" download="pdf-organizer.zip">PDF 정리 실습 파일 다운로드</a>를 눌러 압축을 푸세요. 폴더 안에 실행 파일 `organize-pdfs.py`와 가상의 기차표·영수증·설명서가 들어 있는 `PDF-연습` 폴더가 있습니다. 파일 탐색기에서 압축을 푼 폴더를 열고 주소창에 `powershell`을 입력한 뒤 Enter를 누르세요.

<Image src="/codex-exec-powershell/pdf-organizer-01-before.png" alt="정리하기 전의 가상 영수증, 열차표, 설명서 PDF와 원래 파일 이름" caption="실습 폴더의 PDF 세 장. 문서를 열어봐야 어느 것이 기차표인지 알 수 있습니다." />

Windows에 Python 3.12와 Codex CLI를 준비하세요. 처음이라면 [Python Windows 다운로드](https://www.python.org/downloads/windows/)와 [Codex CLI 설치 안내](https://learn.chatgpt.com/docs/cli)를 참고하세요. PowerShell에서 `codex login`으로 로그인한 뒤 아래 명령으로 PDF 읽기 도구를 설치합니다. 이 설치는 한 번만 하면 됩니다.

```powershell
py -3.12 -m pip install pypdf
```

## 2. 새 이름을 미리 보고 적용하기

**이 명령을 실행하면 PDF별로 바뀔 이름과 들어갈 폴더가 먼저 뜹니다.**

```powershell
py -3.12 .\organize-pdfs.py .\PDF-연습
```

실습에서 `document.pdf`는 `영수증/2026-11-05_모닝커피_영수증.pdf`로, `file-03.pdf`는 `설명서/민트_미니_커피_그라인더_사용설명서.pdf`로 제안됐습니다. 목록을 보고 맞으면 `y`를 입력하세요. Enter만 누르면 미리보기에서 끝납니다.

<Image src="/codex-exec-powershell/pdf-organizer-02-preview.png" alt="PowerShell 실행 결과에서 PDF 세 개의 기존 이름과 정리할 폴더 및 새 이름이 제안된 목록" caption="실제 실행에서 나온 이름 후보입니다. 교통·영수증·설명서 분류와 날짜를 확인한 뒤 적용합니다." />

## 3. 정리본 확인하기

`PDF-연습` 안에 생긴 `정리된 PDF`를 열면 `교통`, `영수증`, `설명서` 폴더에 새 이름으로 복사된 문서가 있습니다. **기존 파일은 원래 이름으로 남아 있어요.** 같은 이름의 다른 문서가 있으면 정리본에 `_2`처럼 번호가 붙습니다.

<Image src="/codex-exec-powershell/pdf-organizer-03-after.png" alt="정리된 PDF 폴더의 교통, 설명서, 영수증에 들어간 세 PDF의 실제 파일 이름" caption="적용 뒤 만들어진 폴더와 파일 이름입니다. 열차표는 교통, 구매 영수증은 영수증 폴더에서 찾을 수 있습니다." />

## 4. 새 PDF가 들어오면 같은 명령 다시 쓰기

`추가-실습`에 있는 `download (2).pdf`를 `PDF-연습`에 복사하고 같은 명령을 다시 실행해 보세요. 이미 정리한 문서는 파일 내용으로 알아보고 건너뜁니다. 실습에서는 **새로 넣은 서점 영수증 한 장만** 이름 후보에 나왔습니다.

<Image src="/codex-exec-powershell/pdf-organizer-04-repeat.png" alt="같은 명령을 다시 실행하자 새로 추가한 서점 영수증 한 장만 정리하는 결과" caption="PDF를 한 장 더 넣고 다시 실행한 결과입니다. 새 영수증만 정리됐습니다." />

자기 문서에 쓰려면 마지막 폴더 이름을 `"$HOME\Downloads\정리할 PDF"`처럼 실제 경로로 바꾸세요. 스크립트는 지정한 폴더 바로 아래의 PDF를 한 번에 최대 20개씩 확인합니다. **이름을 정할 때 각 PDF 앞 두 페이지에서 뽑은 텍스트 일부가 Codex에 전달되니**, 먼저 정리해도 되는 문서만 한 폴더에 모으세요. 이미지로만 된 스캔이나 잠긴 PDF는 `확인 필요`에 표시됩니다.

`codex exec`는 문서별 새 이름과 분류를 반환합니다. 스크립트가 그 목록을 보여주고, 확인한 항목을 새 이름으로 복사합니다.
