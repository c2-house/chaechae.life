### 목차

## 들어가며

웹사이트를 둘러보는데 요청하지 않은 Google 계정 로그인 안내가 나타날 때가 있습니다. 사이트에 로그인하는 방법을 없애고 싶은 것이 아니라, 둘러보는 중에 나타나는 메시지만 줄이고 싶다면 어디를 바꿔야 할까요?

데스크톱 Chrome에서는 **서드 파티 로그인 메시지**를 차단할 수 있습니다. Google 계정에서 Google 로그인 메시지만 끄는 방법도 있지만 적용 범위가 다릅니다. 아래 절차는 2026년 11월 13일 확인한 Google 공식 도움말을 바탕으로 정리했습니다. 실제 설정 변경이나 팝업 동작은 테스트하지 않았습니다.

## Chrome에서 로그인 메시지 차단

먼저 안내가 표시되는 Chrome 창에서 아래 순서로 이동합니다. 메뉴 이름은 Chrome 버전과 언어에 따라 다를 수 있습니다.

1. 오른쪽 위의 `더보기` 메뉴를 열고 `설정`을 선택합니다.
2. `개인 정보 보호 및 보안 → 사이트 설정`으로 이동합니다.
3. `콘텐츠` 아래의 `추가 콘텐츠 설정 → 서드 파티 로그인`을 선택합니다.
4. `ID 서비스의 로그인 메시지 차단`을 선택합니다.
5. 같은 설정 화면에서 차단 항목이 선택되어 있는지 확인합니다. 나중에 다시 표시하려면 같은 화면에서 표시를 허용하는 항목을 선택하면 됩니다.

[Chrome 공식 도움말](https://support.google.com/chrome/answer/14264742?hl=ko)에 따르면 이 설정은 Google에만 한정된 스위치가 아니라 Chrome에서 ID 서비스를 통한 로그인 메시지를 차단하는 선택입니다. 따라서 다른 ID 서비스의 같은 유형 메시지도 영향을 받을 수 있습니다.

설정을 바꿔도 **일반적인 로그인 버튼이 없어지는 것은 아닙니다.** 사이트가 해당 방식을 제공하고 사용할 계정이 있다면 `Google 계정으로 로그인` 버튼이나 사용자 이름과 비밀번호를 이용할 수 있습니다. 자동으로 나타나는 제안과 사용자가 직접 누르는 로그인 버튼은 구분해서 보세요.

## Google 계정에서 메시지 끄기

Chrome의 여러 ID 서비스 메시지가 아니라 Google 로그인 메시지 설정을 바꾸고 싶다면 [Google 계정으로 로그인 설정](https://myaccount.google.com/linkedapps/settings)에서 선택할 수 있습니다.

1. 링크를 열고 변경하려는 Google 계정이 맞는지 확인합니다. 필요하면 해당 계정으로 로그인합니다.
2. `로그인 메시지` 옆의 전환 버튼을 사용 중지합니다.
3. 같은 화면에서 전환 버튼이 꺼져 있는지 확인합니다. 다시 사용하려면 여기에서 켭니다.

[Google 계정 도움말](https://support.google.com/accounts/answer/12849458?hl=ko)에 따르면 이 계정 설정은 Chrome과 일부 다른 브라우저에도 영향을 줍니다. 해당 계정으로 로그인한 Android 기기의 연결된 앱에도 적용되지만, **모든 브라우저의 메시지를 끄는 것은 아닙니다.** 여러 Google 계정을 사용한다면 변경한 계정이 무엇인지 확인하세요.

메시지를 끄는 것과 기존에 연결한 앱에서 Google 계정 연결을 삭제하는 것은 별개입니다. 연결 자체를 정리하려면 Google 계정의 연결된 앱 목록에서 해당 서비스의 연결을 확인해야 합니다.

다시 Google 로그인 메시지를 표시하고 싶다면 계정 설정뿐 아니라 Chrome의 서드 파티 로그인 메시지 허용 여부도 확인해야 합니다. Google 계정 쪽을 켜도 Chrome 쪽이 차단 상태라면 Chrome에는 표시되지 않는다고 Google은 안내합니다.

## 남아 있는 안내 확인

Chrome 설정에서 차단을 선택했는데 비슷한 안내가 남아 있어도 곧바로 설정이 실패했다고 판단하기는 어렵습니다. Google은 방문 중인 **웹사이트나 ID 서비스가 유사한 메시지를 계속 표시할 수 있다**고 설명합니다. 사이트 안에 고정된 로그인 버튼이나 사이트 자체의 가입 안내는 여기서 말하는 Chrome의 메시지와 다를 수 있습니다.

다음 순서로 살펴보세요.

- 안내가 나타난 Chrome 창에서 서드 파티 로그인 차단 항목이 선택되어 있는지 다시 확인합니다. 여러 프로필을 쓴다면 해당 창이 어느 프로필인지도 확인하세요.
- Google 계정 설정을 바꿨다면 메시지와 관련된 계정으로 설정했는지 확인합니다.
- 메시지가 사이트 자체의 로그인·가입 안내라면 해당 사이트의 선택지를 확인합니다. Chrome 설정만으로 모든 유사 안내가 사라진다고 보장할 수는 없습니다.
- 회사나 학교에서 관리하는 브라우저에서 설정을 변경할 수 없다면 관리 정책을 임의로 우회하지 말고 관리자에게 문의합니다.

이 설정은 Chrome 자체에 로그인할지 묻는 안내나 프로필 분리와도 다른 문제입니다. 업무용과 개인용 브라우저 환경을 나누고 싶다면 [크롬 프로필로 계정 분리하기](/blog/chrome-work-personal-profiles)를 참고하세요. 메시지를 차단해도 사이트가 제공하는 일반 로그인 버튼은 그대로 사용할 수 있습니다.
