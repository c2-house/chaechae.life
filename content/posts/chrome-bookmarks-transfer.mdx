### 목차

## 들어가며

새 컴퓨터에서 Chrome을 열었는데 예전에 저장한 북마크가 보이지 않으면 당황스럽습니다. **기존 컴퓨터에 북마크가 남아 있다면 HTML 파일로 내보낸 뒤 새 컴퓨터에서 가져올 수 있습니다.** 이 파일은 북마크의 사본이므로 이후 추가한 북마크까지 자동으로 따라오지는 않습니다.

이 글은 2026년 11월 22일 확인한 [Chrome 공식 도움말](https://support.google.com/chrome/answer/96816?hl=ko)을 바탕으로 컴퓨터에서 파일을 옮기는 절차를 정리했습니다. 대표 이미지는 [Chrome 공식 페이지](https://www.google.com/chrome/)의 화면 일부입니다. 기존 기기에서 데이터가 완전히 사라진 경우의 복구 방법은 아닙니다. 메뉴 이름은 Chrome 버전과 언어에 따라 조금 다를 수 있습니다.

## 이전과 동기화의 차이

HTML 내보내기는 특정 시점의 북마크를 파일로 복사합니다. 새 컴퓨터에서 그 파일을 가져와도 두 컴퓨터가 계속 연결되는 것은 아닙니다. 반면 Google 계정에 저장한 정보를 여러 기기에서 사용하려면 각 Chrome 프로필에서 계정과 저장 항목을 따로 확인해야 합니다.

| 원하는 일 | 살펴볼 방법 |
| --- | --- |
| 기존 북마크의 사본을 새 컴퓨터에 한 번 옮기기 | HTML 내보내기와 가져오기 |
| 같은 계정의 저장 정보를 여러 기기에서 이어 쓰기 | Chrome 로그인과 계정 저장 항목 확인 |
| 업무용과 개인용 북마크를 구분하기 | 각각의 Chrome 프로필과 계정 확인 |

프로필을 나누는 방법은 [크롬 프로필로 업무용과 개인용 계정 분리하기](/blog/chrome-work-personal-profiles)에서 확인할 수 있습니다. **북마크 HTML은 비밀번호, 방문 기록, 열린 탭을 함께 옮기는 전체 프로필 백업이 아닙니다.** 비밀번호는 별도의 관리 방법이 필요합니다.

## 기존 컴퓨터에서 내보내기

먼저 북마크가 실제로 보이는 Chrome 창과 프로필을 엽니다. 다른 프로필에서 내보내면 원하는 목록이 빠질 수 있으니 북마크 관리자에서 필요한 폴더 몇 개를 확인하세요.

1. Chrome 오른쪽 위의 **더보기 → 북마크 및 목록 → 북마크 관리자**를 엽니다.
2. 북마크 관리자 상단의 **더보기 → 북마크 내보내기**를 선택합니다. 브라우저 창 전체의 더보기 메뉴와 북마크 관리자 안의 메뉴를 구분하세요.
3. 파일 저장 창에서 위치와 이름을 확인하고 저장합니다. Chrome은 북마크를 HTML 파일로 내보냅니다.
4. 저장 위치에 파일이 생겼는지 확인하고 USB 등 신뢰할 수 있는 방법으로 새 컴퓨터에 복사합니다. 원본 컴퓨터와 원본 파일은 새 컴퓨터에서 내용 확인이 끝날 때까지 남겨두세요.

HTML에는 북마크 이름과 주소가 들어갑니다. 개인 문서 링크나 업무용 내부 주소가 포함될 수 있으므로 공개 게시판이나 다른 사람과 공유하는 폴더에 무심코 올리지 않는 편이 좋습니다. 회사 기기라면 외부 저장장치와 자료 반출 규정도 확인하세요.

## 새 컴퓨터에서 가져오기

새 컴퓨터에서 북마크를 넣고 싶은 Chrome 프로필을 선택한 후 다음 순서를 따릅니다. 업무용처럼 민감한 링크라면 가져오기 전에 그 프로필의 Google 계정과 저장 항목도 확인하세요.

1. 오른쪽 위의 **더보기 → 북마크 및 목록 → 북마크 및 설정 가져오기**를 선택합니다.
2. **파일 선택**을 누르고 옮겨 온 HTML 파일을 지정한 뒤 **열기 → 완료**를 선택합니다.
3. **더보기 → 북마크 및 목록 → 북마크 관리자**를 열고 필요한 폴더와 사이트를 찾아봅니다.

공식 도움말은 기존 북마크가 없으면 가져온 북마크가 북마크바에 표시되고, 기존 북마크가 있으면 북마크바 끝의 **기타 북마크**에 추가된다고 설명합니다. 화면과 폴더 이름은 환경에 따라 다를 수 있으니 관리자 안에서도 찾아보세요. 대표 북마크 몇 개를 직접 열어 올바른 사이트가 나오는지 확인한 뒤 기존 컴퓨터를 정리하는 것이 안전합니다.

## 북마크가 빠졌거나 중복될 때

파일을 가져왔는데 원하는 북마크가 없다면 먼저 기존 컴퓨터에서 내보낸 **프로필**과 새 컴퓨터에서 가져온 프로필이 각각 맞는지 확인합니다. 기존 컴퓨터의 북마크 관리자에도 없는 항목이라면 HTML로 다시 내보내도 그 항목을 보장할 수 없습니다. 다른 기기나 이전에 보관한 파일이 있는지 살펴보세요.

일부만 보이면 기존 컴퓨터의 폴더와 새 컴퓨터의 가져온 폴더를 비교하고 중요한 링크가 포함됐는지 확인합니다. 가져오기를 여러 번 시도하면 중복 항목이 생길 수 있습니다. 어느 사본이 필요한지 확인하기 전에 폴더를 한꺼번에 삭제하지 마세요.

## 작업을 마친 뒤

파일 이동이 끝나면 북마크 관리자에서 폴더와 링크를 확인하고, 이후 여러 기기에서 계속 같은 자료를 사용할 필요가 있는지 결정하면 됩니다. HTML 파일은 가져온 뒤 자동 갱신되지 않으므로 별도 백업으로 보관할지, 접근 권한이 적절한지 함께 확인하세요.
