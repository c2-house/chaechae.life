### 목차

## 화면을 만지는 맥북의 등장

Apple이 2026년 10월 28일 공개한 **PROLED XDR 맥북 프로는 14형과 16형 모두 화면 터치를 지원합니다.** 스티브 잡스는 2010년 세워진 화면을 오래 만지면 팔이 피로해진다고 봤습니다. 이번 모델은 키보드와 트랙패드를 그대로 두고, 사진 확대처럼 화면을 직접 다루기 편한 동작에 터치를 더했습니다.

Apple 발표와 한국 제품 사양에 따르면 터치 모델에는 `M5 Pro` 또는 `M5 Max`가 탑재됩니다. 제품을 고를 때는 디스플레이 이름 `PROLED XDR`을 확인하세요.

## 잡스가 반대한 수직 터치

2010년 10월 20일 `Back to the Mac` 행사에서 잡스는 iPhone과 iPad의 아이디어를 Mac으로 가져오는 OS X Lion의 방향을 설명했습니다. 멀티터치 제스처도 그중 하나였습니다. 그렇다면 노트북 화면에 손을 대면 되는 것 아니냐는 생각에 대해 그는 이렇게 말했습니다.

> “Touch surfaces don't want to be vertical.”
>
> 터치 표면은 수직으로 놓이는 데 적합하지 않다는 뜻입니다.

[당시 발언을 보존한 영상](https://www.youtube.com/watch?v=mNVsn1P4GlM)에서는 곧바로 팔의 피로에 관한 설명이 이어집니다. 시연에서는 좋아 보여도 잠깐 지나면 피곤해지고, 오래 사용하면 팔이 떨어져 나갈 것 같다는 표현까지 사용합니다. 이어서 수평으로 놓이는 트랙패드와 Magic Mouse를 Mac의 멀티터치 입력 방식으로 제시했습니다. [당일 행사 기록](https://www.iclarified.com/12346/apple-back-to-the-mac-event-live-blog-finished)에서도 Lion 소개와 이 발언의 맥락을 확인할 수 있습니다.

## 키보드와 트랙패드에 더해진 터치

### Touch Bar와 다른 입력 위치

[2016년 맥북 프로의 `Touch Bar`](https://www.apple.com/newsroom/2016/10/apple-unveils-groundbreaking-new-macbook-pro/)는 키보드의 기능 키 자리에 있었습니다. 새 모델은 **콘텐츠가 표시되는 디스플레이에서 Multi-Touch 입력**을 받고, 풀사이즈 기능 키가 있는 Magic Keyboard와 Force Touch 트랙패드를 유지합니다.

[Apple의 발표](https://www.apple.com/kr/newsroom/2026/10/apple-unveils-groundbreaking-macbook-pro-with-proled-xdr-display/)는 웹페이지 스크롤, 사진 핀치 확대, 슬라이드 드래그 앤 드롭, 윈도우 배치 등을 예로 듭니다. 기존 앱에서는 macOS가 터치 입력을 클릭으로 변환하고, 개발자는 업데이트된 제스처 API로 터치에 맞는 경험을 추가할 수 있다고 설명합니다.

작은 아이콘이나 세밀한 선택 영역은 포인터가 편할 수 있습니다. 사용하는 서드파티 앱에 터치 최적화가 필요하다면 Apple 발표의 제공 일정을 확인하세요.

### 짧고 직접적인 조작

터치의 쓸모는 키보드 작업을 모두 바꾸는 것보다 특정 동작에서 찾는 편이 이해하기 쉽습니다. Apple은 Logic Pro의 화면 건반과 드럼 패드, Final Cut Pro의 클립 배치와 핀치 확대, Mac에서의 iOS·iPadOS 앱 터치 동작 테스트를 소개합니다. Creator Studio의 관련 업데이트는 11월 제공 예정입니다.

코드를 쓸 때는 키보드, 실행 중인 앱의 터치 반응을 확인할 때는 화면을 쓸 수 있습니다. 사진은 손가락으로 잠깐 확대하고, 정밀하게 편집할 때 트랙패드로 돌아오는 식입니다.

Apple은 화면을 만질 때 안정성을 높이는 새 힌지와 영상 통화의 흔들림 보정도 소개했습니다.

**Apple 발표와 제품 사양에는 Apple Pencil 지원이 명시되지 않았습니다.** 필기나 드로잉이 구매 목적이라면 사용하는 펜과 앱의 호환성을 확인하세요.

## OLED 화면과 Dynamic Island

### 보는 화면으로서의 변화

터치와 별개로 디스플레이 자체도 달라졌습니다. `PROLED XDR`은 두 개의 자체 발광 픽셀 레이어를 사용하는 탠덤 OLED 디스플레이입니다. 화면을 직접 조작할 일이 많지 않더라도 사진·영상 작업을 한다면 밝기와 색영역, 반사 특성이 더 중요한 선택 이유가 될 수 있습니다.

[공식 제품 사양](https://www.apple.com/kr/macbook-pro/proled-xdr-display/specs/)에는 P3와 Adobe RGB 색영역, 10Hz~120Hz ProMotion, 10,000,000:1 명암비가 기재되어 있습니다. 다만 밝기 수치는 적용 조건을 나누어 읽어야 합니다.

- 전체 화면 지속 밝기는 최대 1,000니트이며, 25°C 미만에서 측정한 조건입니다.
- HDR 콘텐츠의 부분 최대 밝기는 2,000니트입니다.
- SDR의 2,000니트 부분 최대 밝기는 야외 조건에 해당합니다.

Nano-texture 글래스는 별도 옵션입니다. 밝은 곳에서 자주 작업한다면 기본 글래스와 반사 차이를 비교해보세요.

### 화면 위쪽의 상태와 조작

`Dynamic Island`도 Mac에 들어왔습니다. 재생 중인 음악, 실시간 현황, AirDrop 요청 등 필요한 상태를 확인하고 짧게 조작하는 공간입니다. 긴 문서를 입력하는 동안 화면 전체를 터치하는 것보다는, 잠깐 손을 뻗어 음악을 멈추는 장면이 이 기능의 성격을 잘 보여줍니다.

<Image src="/touchscreen-macbook-pro-steve-jobs/02-dynamic-island.jpg" alt="맥북 프로 화면 상단의 Dynamic Island에 표시된 Apple Music 곡 정보와 재생 제어 버튼" caption="Dynamic Island에서 음악 상태와 재생 버튼을 보여주는 공식 화면입니다. 사진: Apple Newsroom." />

Spotlight를 Dynamic Island에서 쓰려면 Siri AI를 사용할 수 있어야 하며 기능을 켜야 합니다. Siri AI 베타는 발표문에서 macOS 27.2, 제품 사양 각주에서 macOS 27로 안내합니다. 구매 전에 실제 OS 버전과 한국어 지원 여부를 확인하세요.

## 한국 가격과 모델 선택

[한국 Apple Store](https://www.apple.com/kr/shop/buy-mac/macbook-pro-proled-xdr)는 **10월 30일 오전 10시 사전 주문 시작, 11월 6일 출시**로 안내합니다.

한국 일반 판매 시작 가격은 다음과 같습니다.

| PROLED XDR 모델 | 한국 시작 가격 |
| --- | --- |
| 14형 M5 Pro | 4,790,000원 |
| 16형 M5 Pro | 5,590,000원 |
| 14형 M5 Max | 7,590,000원 |
| 16형 M5 Max | 8,090,000원 |

14형 M5 Pro의 시작 구성은 15코어 CPU·16코어 GPU, 24GB 통합 메모리, 1TB SSD, 스탠다드 글래스입니다. 메모리·SSD 선택 범위는 칩 구성에 따라 달라집니다. 128GB 메모리나 16TB 저장 공간이 필요하다면 주문 화면에서 해당 옵션을 확인하세요.

별도로 발표된 [M6 맥북 프로 14형](https://www.apple.com/kr/newsroom/2026/10/apple-introduces-the-new-14-inch-macbook-pro-with-m6/)은 Liquid Retina XDR 디스플레이를 씁니다. 터치·OLED 모델의 주문 화면에는 `PROLED XDR`이 표시됩니다.

배터리는 16형 M5 Pro가 **동영상 스트리밍 최대 24시간, 무선 인터넷 최대 17시간**입니다. 14형 M5 Pro는 각각 최대 22시간과 14시간입니다. Apple은 시제품의 화면 밝기를 최저보다 8단계 높이고 키보드 백라이트를 끈 상태에서 Wi-Fi로 Safari의 1080p 영상을 재생했습니다.

## 구매 전에 확인할 작업 방식

이번 변화가 반가운 쪽은 화면 위의 대상을 직접 움직이는 작업을 자주 하면서도, macOS 앱과 키보드 작업을 함께 유지하고 싶은 사용자입니다. 사진 확대, 화면 악기 연주, 터치 앱 테스트처럼 이미 떠오르는 장면이 있다면 매장에서 그 동작을 직접 확인해볼 이유가 있습니다.

반대로 대부분의 시간을 코드나 문서 입력에 쓰고, 집이나 사무실에서는 덮개를 닫아 외장 모니터로 작업한다면 터치를 사용할 기회가 적습니다. 이런 경우에는 터치 지원 자체보다 필요한 성능과 메모리, 내장 화면을 실제로 사용하는 시간에 맞춰 판단하는 편이 낫겠습니다.

구매 전에는 평소 쓰는 앱에서 손가락으로 대상을 정확히 고를 수 있는지, 터치 후 키보드로 돌아오기 편한지, 몇 번 반복했을 때 팔과 어깨가 편한지 확인해보세요.
